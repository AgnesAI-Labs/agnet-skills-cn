# 目标规划与执行复盘专家

版本：`1.1.1`  
Skill ID：`goal-plan-review`  
调用方式：`$goal-plan-review`  
类型：纯对话型目标规划与执行复盘 Skill

## 功能定位

帮助用户把模糊目标转化为可执行行动，并根据用户在当前对话中提供的信息检查进度、复盘差距和调整计划。适用于个人目标，也适用于学习成长、工作任务和项目交付。

## 核心能力

- **目标澄清与可行性分析**：明确目标结果、完成标准、当前基础、期限、资源和现实约束。
- **目标拆解与行动规划**：根据习惯、数量、结果、学习成长或项目交付等不同目标类型，拆分阶段里程碑和具体行动。
- **进度检查**：区分已完成、进行中、受阻、未开始和未知状态。
- **阶段复盘**：按目标类型选择统计口径，比较计划与实际，不把未知数据当成失败。
- **计划调整与中断恢复**：分析变化和障碍，提供可比较的调整方案，不擅自修改用户目标。
- **多目标优先级判断**：识别多个目标之间的期限、资源和精力冲突，辅助安排先后顺序。

## 适用场景

- 习惯养成与日常行动安排
- 学习成长与个人能力提升
- 职业发展和阶段性个人目标
- 工作任务、产品计划和项目交付
- 阶段成果管理、进度检查与复盘
- 计划中断后的恢复与重新规划

## 使用示例

- “我想在30天内完成一个网站原型，帮我拆解计划。”
- “我想每周阅读4次，每次30分钟，帮我安排。”
- “这是我本周的执行记录，帮我复盘完成情况。”
- “原计划已经执行不下去了，帮我分析怎么调整。”
- “我现在有三个目标，但每天只有两小时，帮我排优先级。”

## 使用边界

- 本 Skill 仅在当前对话中提供文字规划、分析和复盘，不创建待办、提醒、日历事项或文件，也不提供跨会话持续追踪。
- 不调用外部工具；文件内容仅能分析用户粘贴或宿主明确提供到当前对话中的内容。
- 可以协助安排通用学习时间和执行任务，但不提供学科教学、具体考试策略或考试结果预测。
- 不提供医疗诊疗、药物建议或个体化健康处方。
- 用户目标、期限、频率和完成标准的变更均由用户决定。

## 来源与版本变化

本 Skill 基于 Agnes 原创 Skill `goal-analyzer-agnes1.17` 升级，并更名为 `goal-plan-review`。

- 将日常习惯规划与复盘扩展到通用目标、工作项目、阶段交付和多目标优先级管理。
- 新增计划调整、中断恢复与条件性趋势估算。
- 继续只在当前对话提供文字建议，不创建待办、提醒、日历事项、文件或跨会话记录。
