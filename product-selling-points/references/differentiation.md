# 差异化与竞品/替代方案分析

## 1. 比较前先定义边界

明确：
- 比较对象是直接竞品、间接竞品还是替代方案；
- 产品版本、套餐、地区和目标客户是否可比；
- 比较时间和资料来源；
- 用户真正关心的选择标准。

如果对象不可比，应说明原因并调整维度，不要硬做排名。

## 2. 建立统一比较维度

按产品类型选择维度，例如：
- 核心功能与能力范围；
- 性能指标及测试条件；
- 易用性、流程和学习成本；
- 适用场景与目标客户；
- 集成、兼容与生态；
- 价格、计费方式和套餐限制；
- 服务、交付、售后与支持；
- 安全、隐私、合规和部署方式。

并非所有维度都适用于所有产品。只比较与用户决策相关的项目。

## 3. 差异状态

每个对比单元使用清楚的状态：
- 支持/明确具备；
- 不支持/明确不具备；
- 有条件支持；
- 资料声称；
- 未找到公开信息；
- 未核实；
- 不适用。

特别注意：
- “未找到公开信息”不等于“不支持”；
- “有该功能”不等于“比竞品好”；
- “功能数量更多”不必然代表用户价值更高；
- “价格更低”必须在相同计费周期、套餐和服务范围下比较。

## 4. 从差异到用户价值

识别差异后，继续判断：
1. 差异是否真实且有证据？
2. 对哪些用户有意义？
3. 在什么场景下影响选择？
4. 是否存在交换条件或短板？
5. 能否形成可被证明的价值主张？

如果差异对目标用户没有实际影响，应列为产品特点，而不是核心卖点。

## 5. 竞品证据记录

至少保留：
- 比较对象与版本；
- 来源名称或链接；
- 资料获取日期；
- 对应功能/指标；
- 证据状态；
- 适用条件；
- 尚未核实的问题。

外部网页信息可能变化，价格、套餐、功能可用范围等尤其需要注明时间。

## 6. 机会输出

可以提出三类机会：
- **可直接表达：** 事实明确、用户价值清楚；
- **需要补证：** 方向可能成立，但缺少关键材料；
- **产品改进机会：** 当前产品并无足够优势，需要产品能力或服务本身改善，而非只改文案。

不得把产品缺陷包装成优势，也不得杜撰竞品弱点。
