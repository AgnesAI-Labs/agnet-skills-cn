# 产品卖点提炼 Skill

版本：1.0.10  
语言：简体中文  
许可：MIT，全文见同目录 `LICENSE`。  
核心定位：产品价值识别、差异化卖点提炼与营销表达

## 文件结构

- `SKILL.md`：主流程、触发条件、执行规范和边界
- `references/`：产品分析、人群价值、竞品差异、营销表达、质量验收方法
- `assets/`：Excel 与 Markdown 交付模板
- `examples/reasoning-example.md`：推导方法示例，不代表任何真实产品

## 使用方式

将 `product-selling-points` 文件夹放入支持 Agent Skill 的技能目录，并确保运行环境允许读取同目录下的 `references/` 与 `assets/` 文件。

用户可以直接提出自然语言任务，例如：
- 帮我从这份产品资料里提炼核心卖点。
- 把这些技术功能转成普通用户能理解的价值表达。
- 对比这几个产品，判断哪些差异值得宣传。
- 审核这组卖点是否有夸大或缺乏证据的地方。

## 交付原则

模板是 Markdown 表格的结构参考，不是已完成分析结果或待下载文件。用户要求表格、xlsx 或文件时，Skill 会按对应模板列在对话中交付结构化 Markdown 表，不创建或声称创建 xlsx，不提供文件路径。直接功能不改写原文。可直接使用的句子只连续引用资料原文，不把「触摸开关」改写成「轻触即可操作」。推断单独成节。不得虚构事实、证据或文件。

## 来源与修改

本 Skill 基于现有 `product-selling-points` 工作副本维护，未提供外部上游链接。1.0.10 将文件请求改为同列 Markdown 表格交付。许可全文见本包根目录 `LICENSE`。
