# 推导示例（仅用于说明方法，不代表任何真实产品结论）

假设用户提供的说明书明确写明：某设备支持预约启动。

| 环节 | 示例内容 | 状态 |
|---|---|---|
| 产品事实 | 支持预约启动 | 以说明书为依据 |
| 直接功能 | 用户可以提前设置启动时间 | 可由功能说明推导 |
| 潜在场景 | 用户希望设备在某个预定时间开始工作 | 场景假设 |
| 潜在收益 | 减少到时再手动启动的步骤 | 合理推断 |
| 适用人群 | 有固定使用时间安排的人 | 待验证的人群假设 |
| 表达方向 | 提前设定启动时间，让设备按计划开始工作 | 不夸大效果 |

不能进一步声称“每天节省 20 分钟”或“适合所有家庭”，除非有相应证据。
