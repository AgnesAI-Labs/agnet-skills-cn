# 语言对话辅导（language-tutor）

按水平练外语对话、词汇和语法纠错，并在当次对话里留下间隔复习列表。

## 适用

- 口语、改一句外语、旅行 / 考试 / 工作场景练习
- 开始前可做大约两分钟水平探测；三条场景分开练
- 证书、法律、医疗文书不翻译，交给专业人士

## 用法

在对话里调用 `language-tutor`，说明要学的语言、水平和这次场景。例如：零基础学西班牙语、先做水平探测；或英语 B1、只练工作里请同事改截止日期。
