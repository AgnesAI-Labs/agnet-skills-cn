# OpenPet（对话版）

在当前对话里养文字电子宠物；也可按要求生成桌宠精灵图。调用名：`openpet`（内容版本 1.2.0-agnes）。

## 适用

- 领养、喂食、玩耍、睡觉、取名
- 默认面板：表情框 + 进度条 + 档案表 + 文末命令
- 年龄涨得慢（喂/玩累计 3 次才长 1 岁）
- 可做桌宠精灵图；可一行/卡片

## 调用示例

- 「领养一只叫团子的宠物，喂它」
- 「陪它玩」
- 「看宠物」
- 「帮我做一张桌宠精灵图」

## 限制

- 状态默认只在当前对话
- 不贴 JSON；喂了是更不饿
- 无外发提醒、无定时扣饥饿
