This repository collects agent skills from several upstream projects. Each skill directory
carries its own license file, and that file governs the skill next to it. The root `LICENSE`
covers only material that originated in this repository.

This file records where the third-party skills came from, so that a distributor or a user can
tell who holds the copyright and which terms apply. Where the import commit recorded an upstream
revision, it is listed. Rows marked "not recorded" were imported before this table existed.
