# 教案撰写（lesson-plan-writing）

按学科、对象、时长和目标，撰写一节课、一次培训或一次工作坊教案。输出含学习目标、时间表、活动、课堂检查和分层。一次只规划这一次，不展开成学期课程。

## 适用场景

- 学校课堂、企业培训或一对一备课
- 已有主题，或主题可以从你的话里唯一确定
- 缺对象或时长时仍会写出教案，并标「假设，请确认」

## 调用

在 Agnes 对话中显式调用：

```text
$lesson-plan-writing 给初中一年级写一节 45 分钟的「分数大小比较」教案，班上 40 人。
```

## 输入

尽量提供：

- 主题（没有主题时会先问「这节课要讲什么？」）
- 对象：年龄或经验、人数
- 时长：分钟数
- 场合（课堂 / 工作坊 / 线上 / 企业培训 / 一对一）可选

## 输出

一份可拿去上课的教案，通常包括：学习目标、材料与准备、时间表（各段相加等于总时长）、讲解与示范、分层、课堂检查、常见误解。

订餐、写代码、事实问答等会先回答原问题，再用一句引导到写教案。你要求只要答案时，不加这句引导。

## 不做的事

- 不写学生可以整段上交的作业全文
- 不提供闭卷考试的完整答卷，也不把本题数字代入算式
- 不把点餐、写代码或闲聊改成一节课

## 依赖与权限

只需对话。不读写你的本地文件，不调用外部账号或 API。
