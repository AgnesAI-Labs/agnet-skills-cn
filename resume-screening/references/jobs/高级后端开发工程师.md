【核心底层要求】
1.资深后端基本功：5-8 年一线开发经验，精通 Java（Spring 生态），具备 Python/Go/PHP 等多语言实战能力者优先。
2.业务拆解与重构能力：具备模块级深度业务技术梳理能力，能独立承担从“混乱逻辑”到“清晰组件”的改造落地。
3.规范意识与影响力：关注代码质量，能主动输出合理的编码规范建议，带动周边同学的工程素养提升。
4.务实的 AI 工程观：熟练使用 AI 编程工具（Cursor/Trae 等）解决真实问题，对生成代码的边界有判断力，能用AI工具提升真实冲刺交付效率；
 
【岗位职责】
{此项必备条件}：最近两份岗位，要求仍然是深度参与一线研发或一线项目协调的，且没有经理及以上岗位经历的；我们更多需要的是能一线参与研发和架构的候选人，而不太需要习惯了团队管理的人员；涉及明显的高比例管理岗职责的候选人，本项评分直接以低分（10分以下）处理；
1.业务系统优化（核心）：承担企业内部数据分析系统和业务核心系统的模块梳理、业务组件识别及代码改造优化，参与架构演进；
2.一线研发与交付：参与代码评审、技术方案设计。并能独立负责复杂业务组件的方案分析、编码及性能优化，支持冲刺确保交付质量与进度。
3.基建优化：参与后端基础设施（日志、通用工具包、通用业务组件）的改良。
4.辅助AI提效：将 AI 工具深度融入日常工作流（详细方案分析、样板代码生成、单测补齐等），提升交付效率。参与AI研发设施优化。
5.技术分析引导：通过有效的模块分析方案评审，梳理清楚模块边界，支持团队成员提升业务理解与代码设计能力。
 
【岗位必备条件】
{此项必备条件}：必需严格筛选工作经验年限5-9年，此范围外的候选人，本项评分直接以低分（10分以下）处理；
1.学历与经验：5-9 年后端开发经验，统招本科及以上学历，计算机相关专业。
2.技术栈：精通 Java 及 Spring Boot/Cloud 技术生态及实践，理解JMM及JVM核心机制，理解并熟练使用多线程编程，了解SpringBean生命周期管理及容器机制；具备 Python / Go / PHP 等任一其他语言的项目实践经验者优先。
3.中间件与存储：深入理解 MySQL/PostgreSQL（索引、锁、事务）、Redis、Kafka/RocketMQ、xxl-job等常用技术栈；熟练使用 Linux 基本日志及文件处理命令。
4.设计与重构能力（核心）：
（1）具备模块级深度业务技术梳理能力，能将模糊需求转化为清晰的数据模型与接口契约；
（2）熟练掌握常用设计模式，并有实际的组件化封装经验（如策略模式解耦业务分支、模板方法规范流程）；
5.工程素养：具备代码洁癖，能主动识别并消除重复代码；重视单元测试与异常处理。
6.AI 工具链：日常使用 AI 编程工具（Cursor、Claude Code、Trae、CodeBuddy等）解决实际问题，并能甄别生成代码的潜在风险。

【实践经验描述标准】
各个项目或工作经历案例中，如果只有技术名词或业务术语堆砌，没有较多体现具体所解决的问题场景，或者没有呈现出对问题进行深度分析过程的，都是属于低分案例；这种情况，本项匹配度评分，以低分（10分以下）处理；
只有既有专业术语名词，同时也描述了对应解决的问题或者分析该问题为何使用该项技术的项目案例描述，才能得到高匹配分，两者缺一均不可。
