# 简历匹配度评分细则

本文件是逐维度打分的**唯一标准依据**。5 个维度各满分 20 分，总分满分 100 分。

## 零、评分执行顺序（必须遵守）

对每一份简历，逐维度按以下顺序打分：

1. **先查硬性淘汰规则**：定位岗位模型中对应维度下以 `{此项必备条件}：` 开头的行。若简历事实命中该行描述的淘汰情形，**该维度直接取规则指定的分数，不得再按分数区间评分**。
2. **再按分数区间评分**：未命中淘汰规则的维度，按下表对应维度的区间标准打分。
3. **产出整数分**：每个维度输出 0-20 的整数。

维度顺序固定为：`核心底层要求` → `岗位职责` → `岗位必备条件` → `岗位加分项` → `实践经验描述标准`。

---

## 1.【核心底层要求】（满分 20 分）

将简历内容与岗位模型中【核心底层要求】部分逐条比对。

| 分数区间 | 判断标准 |
|---------|---------|
| 18-20 分 | 完全满足所有核心底层要求项，且有深度实践案例佐证 |
| 14-17 分 | 满足大部分核心要求项，有一定实践佐证 |
| 10-13 分 | 满足部分核心要求项，佐证一般 |
| 6-9 分 | 少量满足核心要求项，缺乏有效佐证 |
| 0-5 分 | 几乎不满足核心底层要求 |

## 2.【岗位职责】（满分 20 分）

将简历中的工作经历与岗位模型中【岗位职责】部分逐条比对。

| 分数区间 | 判断标准 |
|---------|---------|
| 18-20 分 | 有与岗位职责高度匹配的丰富实践经验，能独立承担核心职责 |
| 14-17 分 | 有与大部分职责匹配的实践经验 |
| 10-13 分 | 有与部分职责匹配的经验 |
| 6-9 分 | 有少量相关经验 |
| 0-5 分 | 几乎无相关职责经验 |

## 3.【岗位必备条件】（满分 20 分）

将简历信息与岗位模型中【岗位必备条件】部分逐条比对。

| 分数区间 | 判断标准 |
|---------|---------|
| 18-20 分 | 完全满足所有必备条件（学历、经验年限、技术栈、中间件等） |
| 14-17 分 | 满足大部分必备条件，仅个别项有差距 |
| 10-13 分 | 满足部分必备条件，若干关键项有差距 |
| 6-9 分 | 少量满足必备条件，多项关键条件不满足 |
| 0-5 分 | 几乎不满足必备条件 |

## 4.【岗位加分项】（满分 20 分）

将简历内容与岗位模型中【岗位加分项】部分逐条比对。

| 分数区间 | 判断标准 |
|---------|---------|
| 18-20 分 | 具备多项加分项且有实践案例佐证 |
| 14-17 分 | 具备部分加分项，有一定佐证 |
| 10-13 分 | 具备少量加分项 |
| 6-9 分 | 几乎无加分项 |
| 0-5 分 | 无任何加分项 |

若岗位模型对本维度写明了「满足 N 项及以上得满分、满足 1 项得 X 分、都不满足得 0 分」这类计分规则，**以该规则为准**，覆盖上表。

## 5.【实践经验描述标准】（满分 20 分）

依据岗位模型中【实践经验描述标准】部分的评判标准，评估简历中项目经验的描述质量。

| 分数区间 | 判断标准 |
|---------|---------|
| 18-20 分 | 既有专业术语名词，同时也清晰描述了对应解决的问题，以及分析该问题为何使用该项技术的项目案例描述 |
| 14-17 分 | 有专业术语和部分问题描述，但分析深度一般 |
| 10-13 分 | 有技术名词但问题描述不够清晰，缺乏问题分析过程 |
| 6-9 分 | 仅有技术名词和专业术语堆砌，没有体现对应所解决的问题，也没有呈现出如何对问题进行分析的项目实践案例 |
| 0-5 分 | 实践经验描述匮乏或完全无法评估 |

若岗位模型对本维度写明了「仅术语堆砌者本项以 10 分以下处理」这类规则，**以该规则为准**，覆盖上表。

---

## 通用红线

1. 简历原文中未体现的内容，一律不得计分。
2. 简历内容不足以评估某维度时，该维度如实给 0-5 分，不得捏造、不得跳过后按满分处理。
3. 单维度不得超过 20 分，总分不得超过 100 分。
4. 每个维度都必须给出分数，不得省略任何维度。
