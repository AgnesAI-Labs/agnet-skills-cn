# 事实核查与主张判定规则

## 1. 可核查性分类

- **事实断言**：有可观察记录或独立证据的断言（日期、地点、主体、产品功能、数量、事件等）。
- **数值断言**：应核对指标名称、单位、分子分母、统计范围、时点、数据源和是否经过四舍五入。
- **直接引述**：检查原文逐字一致、删节号、上下文、说话者和引用版本。译文应标明“译述”而非假装为原话。
- **因果断言**：要求干预、对照、排除混杂因素等合理因果证据；时间先后/同向变化只能支持关联，不直接证明因果。
- **政策/规则断言**：核对司法辖区、实施/生效日、修订版及是否适用于具体主体；不能从一般规则直接推出个案法律建议。
- **观点与偏好**：不做事实真假判断；可以核查意见中所包含的客观子主张。
- **预测、推测或传言**：不可把未来结果判作既成事实；可检查数据、假设和传播链。

## 2. 主张拆分与优先级

1. 保留原句，至少记录文段、页码、表格单元格或可定位的上下文之一。
2. 一个主张只保留一个可独立判断的核心陈述；多个数字或时间点各自拆分。
3. 去除纯修辞与重复，但不要丢掉“可能”“截至”“约”“样本中”等限定词。
4. 风险越高越优先：对读者决策影响大的数字、健康安全、财务、法律、商业宣传、标题中心论断。
5. 文档过长：明确总数、核查的条数、选择原则与未检查范围。抽样仅支持抽样范围内的判断。

## 3. 状态决策原则

| 主状态 | 最低判定依据 | 常见误区 |
| --- | --- | --- |
| 有证据支持 | 已查看的、相关且可靠证据直接支持限定后的表述 | 仅见二次转载就判通过 |
| 部分支持 | 基本事实有证据，但原话忽视范围/条件/量级 | 以完全正确的语气复述夸大措辞 |
| 与证据冲突 | 已核对的强相关证据与之直接矛盾 | 不说明证据版本/日期 |
| 证据不足 | 有相关但不充分、非独立或相互冲突的证据 | 说成“错误”或“假新闻” |
| 暂无法核实 | 缺乏可访问资料或访问条件受限 | 用常识/印象弥补缺失来源 |
| 已过时 | 对应旧时点/旧版本的内容被误当现况，时效差异可确认 | 仅凭资料旧就认定它一定不成立 |

### 关键例外

- 单一官方来源通常可证明“该机构发布了这项数据/声明”，不一定证明该机构统计值独立准确。
- 原文明确是“根据某机构的统计，...”时，核查目标可分为“机构是否如此发布”和“数据是否真实可靠”两个层次。
- 数据差异可能来自去重口径、计算周期、币种、年份或版本，不要过早定为冲突。
- 对科学研究：结论不能超出研究人群、数据和方法；个案、样本研究和系统综述的支持力不同。
- 对图表/截图：确认图轴、起点、百分比变化与绝对变化，图是否被截断或拼接；无法判断图片是否篡改时声明限制。
- “已过时”需有可说明的新旧时点差异；如果无法访问现行资料，优先“暂无法核实”，不要仅因为页面旧就下“已过时”结论。

## 4. 数字核查清单

- 计数/百分比/百分点：`从 20% 到 25%` 是 `+5 个百分点`，相对增幅是 `25%`，不可混用。
- 增长率与基数：增长 `50%` 不能凭空推出新增人数或总量。
- 单位与币种：万/亿、美元/人民币、月度/年度、吨/千克。
- 样本：N、抽样方式、调查对象、回收时间、缺失值和权重。
- 时间：观测期、发布期、访问期分别记录。
- 聚合：去重用户与事件次数、均值与中位数、自然日与滚动窗口。
- 因果：影响变量和潜在混杂因素；没有合理设计只写“同时出现/存在相关”。

## 5. 可审计记录

每个 `claim_id` 至少保存：原句、位置、可核查类型、核查时点、结论、判断理由、必要的修订建议。已找到的每条证据独立标记 ID 和来源位置；查不到时记录尝试的范围或工具受限原因。保留不同来源的矛盾，不覆盖掉不利证据。
