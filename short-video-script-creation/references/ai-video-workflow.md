# AI 视频镜头规划参考

## 1. 适用范围

用于文生视频、图生视频、参考图驱动、虚拟角色、AI 动画和多镜头 AI 短片的前期规划。此文件不代表 Skill 本身能够生成视频。

## 2. 工作顺序

1. 先确定故事、信息和情绪目标；
2. 设计完整镜头顺序；
3. 为主要角色、场景、服装、道具建立一致性描述；
4. 将复杂动作拆分为可控镜头；
5. 为每个镜头写独立提示词；
6. 检查镜头之间的连续性；
7. 标出需要用户提供的参考图、产品图或素材；
8. 为可能生成失败的镜头准备替代描述。

## 3. 单镜头提示词结构

可按任务选择以下信息：

- **主体：** 人物、产品、动物、物体或场景；
- **主体特征：** 外观、服装、材质、颜色、可识别特征；
- **动作：** 一个主要动作及其先后过程；
- **环境：** 地点、时间、天气、背景元素；
- **构图：** 主体位置、景别、视角、焦点；
- **镜头：** 固定、推进、跟拍等；
- **光线与色彩：** 光源、明暗、色温和整体氛围；
- **视觉风格：** 写实、动画、胶片质感等；
- **时长与节奏：** 镜头持续时间及动作速度；
- **连续性约束：** 角色、服装、道具、场景和光线需保持一致；
- **限制项：** 工具明确支持时再使用负向提示。

提示词应以具体可见内容为主。避免只堆砌“超高清、极致细节、电影级、震撼”等形容词。

## 4. 跨镜头一致性

为多镜头作品建立简短的“连续性设定”：
- 角色外观、年龄表现、发型、服装和配饰；
- 产品外观、颜色、尺寸比例、Logo 位置；
- 场景布局、时间、天气和光源方向；
- 道具位置及状态；
- 色彩、光线和整体视觉风格；
- 已发生事件对下一镜头的影响。

每个镜头只重复与该镜头有关的关键约束，避免提示词冗长且相互矛盾。

## 5. 动作复杂度

- 一个镜头优先表现一个主要动作或状态变化；
- 多人物互动、复杂手部动作、文字展示和精确产品操作可能较难稳定生成；
- 重要文字、品牌标识和 UI 内容可考虑后期叠加，不要默认让生成模型准确绘制；
- 对产品外观和品牌信息要求严格时，优先使用用户提供的参考素材，并提示生成结果需要核验；
- 复杂动作拆镜头，避免单个镜头同时要求多个主体完成多阶段动作。

## 6. 输出建议

按镜头输出：
- 镜头编号与叙事作用；
- 画面描述；
- 生成提示词；
- 参考素材需求；
- 连续性约束；
- 预计时长；
- 生成风险和替代方案。

若用户指定具体 AI 视频工具，只有在了解或核实该工具的功能和参数后，才使用其专属参数格式。否则先提供通用提示词。
