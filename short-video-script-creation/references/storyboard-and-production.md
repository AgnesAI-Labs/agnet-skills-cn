# 分镜与拍摄准备规范

## 1. 分镜的作用

分镜需要让拍摄者、剪辑者或 AI 视频操作者理解：
- 这个镜头在内容中承担什么作用；
- 观众实际会看到什么；
- 人物、产品或环境如何变化；
- 镜头需要什么画面和声音；
- 需要准备哪些资源；
- 如何与前后镜头衔接。

“有画面感”不等于“可执行”。尽量使用可观察、可操作的描述。

## 2. 景别与机位参考

- 远景/全景：交代空间、环境、人物位置；
- 中景：人物动作、互动和演示；
- 近景：表情、细节动作和情绪；
- 特写/大特写：产品细节、关键物件、局部动作；
- 主观视角：模拟人物观察；
- 俯拍/顶拍：展示桌面、流程或物品布局；
- 低角度/高角度：根据表达目的使用，不要为了变化而变化。

## 3. 运镜与构图

可选方式包括固定、推近、拉远、横移、跟拍、摇摄、俯仰、环绕等。只在能够增强信息、空间关系或情绪时使用。

构图说明应聚焦主体位置、视觉焦点、前后景关系、留白和字幕空间。不要给每个镜头堆叠“电影感、大片感、史诗感”等无法执行的形容词。

## 4. 分镜表建议字段

列名与 `templates/storyboard-template.xlsx` 一致。可选列可以留空，不要改名。

| 字段 | 必填程度 | 说明 |
|---|---|---|
| 镜头编号 | 必填 | 便于引用和修改 |
| 段落/场景 | 建议 | 关联脚本结构 |
| 起始时间(秒) | 按需 | 时间线明确时填写 |
| 结束时间(秒) | 按需 | 与起始时间同时填写 |
| 镜头时长(秒) | 必填 | 大于 0 的预计秒数 |
| 画面内容与人物动作 | 必填 | 具体、可观察 |
| 景别 | 建议 | 根据画面需要填写 |
| 机位/角度 | 建议 | 平视、俯拍、仰拍等 |
| 运镜/镜头运动 | 按需 | 不需要时可留空 |
| 构图/视觉重点 | 按需 | 主体位置和焦点 |
| 口播/对白/旁白 | 按需 | 与脚本保持一致 |
| 屏幕字幕/图形 | 按需 | 标题、字幕、数据等 |
| 音乐/音效/环境声 | 建议 | 环境声、音乐、音效 |
| 转场/剪辑提示 | 按需 | 说明衔接方式 |
| 场景/人物/道具 | 建议 | 对应制作资源 |
| 拍摄/生成方式 | 建议 | 实拍、素材、动画、AI 等 |
| 备注/待确认 | 按需 | 待确认、风险或替代方案 |

## 5. 拍摄素材清单

至少包含：
- 编号；
- 类别（人物/场景/道具/设备/图片/视频/音频/图形/授权等）；
- 素材或物品名称；
- 用途及对应镜头；
- 规格、数量或时长；
- 来源（已有、自制、采购、授权、生成、待获取）；
- 当前状态；
- 负责人和准备时间（未知则留空/待确认）；
- 授权、版权或使用限制；
- 备注与替代方案。

## 6. 制作条件与低成本替代

用户条件有限时，不要只指出做不到。提出可执行替代：
- 没有演员：第一视角、手部特写、屏幕录制、静物镜头或旁白；
- 没有实景：已有素材、桌面布景、图形动画或 AI 生成；
- 没有专业设备：自然光、稳定支撑、手机收音优化；
- 预算有限：减少场景和演员，集中拍摄同一地点的镜头；
- 缺少素材：用明确的待补清单区分必须素材与可替代素材。

## 7. 拍摄顺序

脚本叙事顺序不一定等于现场拍摄顺序。需要时按地点、演员、道具、光线或设备安排拍摄顺序，并保留原镜头编号，便于后期剪辑对应。
