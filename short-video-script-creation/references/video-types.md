# 视频类型创作参考

本文件用于帮助选择创作方式。类型可以混合，例如“产品测评 + 真人口播 + 场景演示”。不要将分类当作僵化模板。

## 1. 真人口播与观点表达

**适合：** 经验分享、观点表达、个人账号、职业知识、生活建议。

**重点：**
- 开场尽快呈现具体问题、经历、判断或反常识观察；
- 主体围绕一个核心观点展开，避免一条视频塞入太多主题；
- 用真实例子、对比、场景或个人经验支撑观点；
- 结尾可以总结、提出问题或留出思考，不必每次强行号召关注。

**常见结构：** 场景/问题 → 观点 → 理由/例子 → 结论。

**镜头建议：** 主机位口播为主，必要时插入相关 B-roll、屏幕录制、关键词字幕和实物演示。

## 2. 知识科普与教程

**适合：** 概念解释、技能教学、操作步骤、专业知识普及。

**重点：**
- 明确观众学完能理解或完成什么；
- 专业概念先解释，再给例子；
- 步骤类内容按真实操作顺序展开；
- 重要限制、适用条件和例外情况不能为了压缩时长而删除；
- 需要展示操作时，画面必须与讲解同步。

**常见结构：** 问题/目标 → 概念或准备 → 步骤/解释 → 示例 → 总结/提醒。

## 3. 产品演示与商品介绍

**适合：** 商品展示、软件功能介绍、服务介绍、产品使用教程。

**重点：**
- 从用户场景或需求切入，不要只罗列参数；
- 把功能转化为可观察的使用过程；
- 卖点必须有产品资料、实际演示或可靠证据支撑；
- 区分产品事实、体验描述和营销表达；
- 对比内容应说明比较条件，避免不公平或无法核实的结论。

**常见结构：** 使用场景 → 用户问题 → 产品/功能演示 → 价值解释 → 适用人群/下一步。

## 4. 品牌广告与创意短片

**适合：** 品牌形象、活动宣传、产品广告、商业创意视频。

**重点：**
- 先确定核心记忆点或情绪，再决定视觉表达；
- 产品/品牌信息应自然进入创意，而不是结尾突然贴 Logo；
- 兼顾品牌识别、产品事实和传播目标；
- 不以空泛口号代替具体画面；
- 需要多版本时，确保创意路线真正不同（叙事、视觉、情绪或表现手法）。

**常见结构：** 情绪/场景建立 → 创意展开 → 品牌/产品进入 → 核心信息 → 收束。

## 5. 剧情、情景短剧与微故事

**适合：** 生活短剧、反转故事、情感故事、幽默片段、品牌剧情。

**重点：**
- 明确人物、目标、关系和场景；
- 事件必须推动人物或情节发生变化；
- 冲突应来自人物目标、误解、选择或环境，不要只靠无意义争吵；
- 对白要符合人物身份和关系；
- 反转应有铺垫，不能依靠观众无法提前获知的关键信息硬拗；
- 控制人物数量和场景数量，匹配制作资源。

**常见结构：** 人物/情境 → 触发事件 → 冲突升级 → 选择/转折 → 结果/余味。

## 6. Vlog、生活记录与旅行/探店

**适合：** 日常记录、旅行、美食、探店、活动、幕后花絮。

**重点：**
- 不必把每个动作都写成台词；
- 以事件线、时间线、体验变化或一个明确主题串联素材；
- 保留真实环境声、现场细节和自然反应；
- 旁白用于补充背景、感受和信息，不要重复画面；
- 用户尚未发生的体验不能写成已发生事实。

**常见结构：** 出发/期待 → 过程中的关键片段 → 意外/发现 → 体验总结。

## 7. 测评、对比与体验分享

**适合：** 产品测评、工具体验、服务体验、方案对比。

**重点：**
- 明确测评对象、条件、维度和体验范围；
- 将事实、个人感受和推断分开；
- 负面结论应有具体依据；
- 对比时保证条件尽可能一致；
- 不伪造使用过程、测试结果或评价。

**常见结构：** 测评问题 → 条件/标准 → 实测过程 → 结果与局限 → 适用建议。

## 8. 访谈、人物故事与纪实

**适合：** 人物采访、团队故事、客户故事、纪录短片、幕后记录。

**重点：**
- 设计采访主题和问题层次，而不是预设受访者必须说出的答案；
- 将事实核查与叙事剪辑分开；
- 受访者原话不得被改写成其未表达的观点；
- 旁白、字幕和画面不能改变原意；
- 明确肖像、录音和素材授权。

**常见结构：** 人物/背景 → 核心问题 → 经历/细节 → 变化/观点 → 收束。

## 9. 活动、节日与公益宣传

**适合：** 活动预告、活动回顾、招生招聘、节日内容、公益传播。

**重点：**
- 核对时间、地点、对象、参与方式和限制条件；
- 信息型视频优先保证清楚，不要为了创意牺牲关键事实；
- 行动引导应具体且真实；
- 公益内容避免消费受助者、夸大效果或泄露隐私。

## 10. AI 视频与动画

**适合：** 文生视频、图生视频、虚拟人物、动画短片、概念片。

**重点：**
- 先写清楚镜头要表达的事件，再写生成提示词；
- 角色、服装、道具、环境和光线要保持跨镜头一致；
- 单个镜头尽量聚焦一个主要动作或变化；
- 复杂动作拆成多个镜头，不要要求单镜头完成过多连续事件；
- 预留生成失败、角色漂移和画面不可控的替代方案。
