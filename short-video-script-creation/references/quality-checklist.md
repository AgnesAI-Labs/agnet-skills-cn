# 短视频脚本质量验收清单

交付前按任务范围检查。与任务无关的项目标记“不适用”，不要为了勾满清单而增加无关内容。

## A. 目标与创意

- [ ] 视频主题、目标和受众明确。
- [ ] 创意方向与视频类型、受众和制作条件匹配。
- [ ] 开场建立了真实的观看动机。
- [ ] 内容有明确主线，没有多个主题生硬拼接。
- [ ] 多方案之间存在实质差异（如用户要求多方案）。

## B. 内容与语言

- [ ] 主体内容有信息增量、故事推进或体验价值。
- [ ] 结构顺畅，段落之间衔接自然。
- [ ] 口播自然、可朗读，不像书面报告。
- [ ] 台词符合人物身份、关系和场景。
- [ ] 没有无意义重复、空泛口号或强行营销。
- [ ] 结尾与视频目标匹配，不机械添加互动口号。

## C. 事实与合规

- [ ] 产品、数据、价格、功效、案例和评价有来源或明确标注待确认。
- [ ] 真实体验与虚构设定清楚区分。
- [ ] 未将推测包装成事实。
- [ ] 分镜列名与模板一致，包括「镜头时长(秒)」「画面内容与人物动作」「起始时间(秒)」「结束时间(秒)」。
- [ ] 用户未提供购买链接、店铺、购物车或投放渠道时，没有写购物车、下单或私信购买。
- [ ] 已确认的放置、操作、数量和设备出现在对应镜头动作中，没有被换成另一种常见拍法。
- [ ] 没有使用经历或可核验数据时，未预写疗效、体感、疼痛变化或医疗判断，也未交付可填空后当真实测评发布的口播正文。
- [ ] 图片、音乐、字体、视频、肖像和商标的授权风险已提示。
- [ ] 未复刻受版权保护的具体脚本或独特表达。

## D. 视听与分镜

- [ ] 每个镜头都有清楚的画面任务。
- [ ] 画面描述可观察、可执行，不是空泛词语。
- [ ] 旁白与画面互相补充，而非机械重复。
- [ ] 景别、机位、运镜和构图符合表达需要。
- [ ] 字幕、声音和转场信息在需要时已提供。
- [ ] 人物、服装、道具、场景和时间线保持一致。

## E. 时长与制作可行性

- [ ] 口播时长根据实际语速、停顿和演示时间估算。
- [ ] 镜头时长合计与目标时长基本一致。
- [ ] 片头、片尾、转场和留白已纳入时间估算。
- [ ] 所需演员、场景、道具和素材可获得，或已标注待准备。
- [ ] 对高成本或难实现镜头提供替代方案。
- [ ] 严格时长任务建议实际朗读或试拍计时。

## F. 文件交付

- [ ] 文件名清楚，格式正确。
- [ ] 表格字段完整、列宽合理、可筛选和阅读。
- [ ] 脚本、口播稿、分镜表中的关键信息一致。
- [ ] 未填造负责人、日期、素材状态或授权信息。
- [ ] 待确认事项清晰列出。
- [ ] 文件确实已生成并可访问；没有虚构下载链接。

## 问题等级

- **阻断问题：** 事实错误、核心目标不清、关键镜头无法执行、时长严重不符、交付文件损坏。
- **重要问题：** 结构不顺、口播不自然、镜头缺少必要信息、素材需求遗漏。
- **一般优化：** 个别措辞、镜头节奏、字幕或视觉细节可进一步提升。

先修复阻断和重要问题，再处理一般优化。
