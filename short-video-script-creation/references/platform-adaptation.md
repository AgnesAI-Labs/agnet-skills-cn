# 平台与渠道适配参考

## 1. 平台适配的目标

平台适配不是简单添加话题标签或把视频裁成竖屏，而是根据观看场景调整：
- 内容开场和信息进入速度；
- 视频长度与信息密度；
- 画面比例、字幕位置和可读性；
- 用户是否有声音、是否快速浏览；
- 受众熟悉程度和内容上下文；
- 行动引导和后续承接方式。

## 2. 平台中性优先

用户未指定平台时，先创作平台中性的脚本，不擅自假设某个平台的审核、推荐或流量规则。

用户指定平台时，可根据用户提供的要求和已知的稳定特点做适配；对可能变化的尺寸、时长、审核或推荐规则，不能凭记忆声称是最新标准。

## 3. 多平台改编

同一主题适配多个渠道时：
1. 保留核心事实和内容主张；
2. 明确各平台的主要受众与观看场景；
3. 调整开场、信息密度、节奏和时长；
4. 按平台阅读习惯调整字幕、画幅和画面安全区；
5. 检查各版本是否仍然准确；
6. 给出差异说明，避免只复制同一稿件。

## 4. 最新规则核验

如果用户要求“按当前最新平台规范”制作，且具备联网能力：
- 优先查看平台官方创作者中心、帮助中心或官方公告；
- 记录核验日期；
- 区分强制规范、建议和经验做法；
- 无法确认的内容标注待复核。

如果无法联网，不要伪造最新规则。可先按通用规范完成内容，并将需要用户核对的参数单独列出。

## 5. 通用画面检查

- 重要信息不要贴近画面边缘；
- 字幕保证足够对比度和阅读时间；
- 关键动作和产品细节不要被字幕遮挡；
- 画幅裁切后主体仍然完整；
- 无声观看时，关键信息仍可通过字幕或画面理解；
- 有声观看时，字幕与口播保持一致。
