# 短视频脚本创作 Skill

**Skill ID：** `short-video-script-creation`  
**版本：** 1.0.5  
**许可证：** MIT，全文见 `LICENSE`

## 用途

帮助用户把一个主题、产品、故事、素材或创作想法，转化为适合实际制作的短视频方案。覆盖创意构思、内容结构、脚本与口播、分镜设计、拍摄准备、AI 视频镜头提示词和脚本迭代。

适用对象包括普通创作者、自媒体运营、企业与商家、内容团队、教师、编导及 AI 视频创作者。

## 文件结构

- `SKILL.md`：主入口、工作流程、调用路由、交付与质量要求。
- `LICENSE`：MIT 许可全文，覆盖本包内的说明、参考、模板和脚本。
- `references/`：按需读取的创作方法、视频类型、分镜规范、平台适配及验收标准。
- `templates/`：脚本、口播稿和 Excel 分镜/拍摄素材模板。
- `scripts/validate_storyboard.py`：可选的 CSV 分镜表结构与时长检查脚本。

## 使用方式

将 `short-video-script-creation` 文件夹作为一个 Skill 安装或导入。确保 `SKILL.md` 位于 Skill 根目录。

用户可以直接用自然语言提出需求，例如：

- “帮我写一个 45 秒的咖啡知识口播视频。”
- “根据这份产品资料做一个 30 秒广告脚本和分镜拍摄表。”
- “我想拍一个独居生活短片，先给我几个创意方向。”
- “把这份讲稿改成适合短视频的表达，并拆成镜头。”
- “我要用 AI 视频工具制作一段科幻短片，帮我设计连续镜头和生成提示词。”

## 设计原则

1. 不把所有视频类型套进同一种脚本模板。
2. 不强制用户填写完整参数；缺少非关键参数时采用合理默认值并说明。
3. 交付深度服从用户任务：简单需求不强制输出全套表格，完整制作需求不能只给一段文案。
4. 把创意、语言、画面、声音、时长和制作条件作为一个整体设计。
5. 不编造产品事实、真实体验、数据、评价或拍摄素材。
6. 不把平台规则、推荐机制或内容趋势写成永久不变的事实。
7. 不声称已拍摄、剪辑、生成或发布视频，除非确实调用了相应工具并成功完成。
8. 用户已经确认的放法、操作和设备数量，必须出现在对应镜头里。
9. 没有真实体验或可核验数据时，不把测评写成已经发生的使用结论。
10. 分镜列名使用模板中的名称。用户没给购买渠道时，不补写购物车或下单入口。
