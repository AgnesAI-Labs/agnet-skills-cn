# 简历内容优化

以招聘专家视角研究目标岗位、整理个人经历，并完成简历诊断、岗位匹配、内容优化、版式建议和招聘视角审核。不负责文件导出、模板填充、自动投递，也不保证录用。

## 用法

导入本目录或对应 ZIP。调用名为 `resume-content-optimization`，入口文件为 `SKILL.md`。

可以请它诊断现有简历、改写一段经历、按目标岗位定制，或从已确认事实整理可复制的简历正文。没有目标岗位时，它会先询问，或标明通用版。

## 目录

- `SKILL.md`：主入口与工作流
- `README.md`：用法与范围
- `LICENSE`：MIT 许可全文
- `references/`：岗位研究、经历挖掘、招聘评审、写作、模板选择和事实核验
- `assets/templates/`：3 种经筛选保留的可编辑 DOCX 单页简历格式与样式模板
- `assets/workbooks/`：可供用户手工使用的岗位研究、经历素材、岗位匹配、修改对照和审核评分参考表

## 重要说明

- 搜索到的 JD 只代表样本，不能被描述为整个行业的绝对标准。
- 简历内容必须能追溯到用户提供或确认的事实。待确认内容不写入可直接使用的简历正文。
- 当前保留三种单页模板，均用于简约、信息密度适中的中文简历。严格 ATS 场景仍应优先单栏、线性正文结构。
- 模板仅定义格式与样式，不是内容模板。不得复用模板中示例姓名、照片、联系方式、公司、职位、日期、项目或任何经历内容；简历正文只能来自用户提供或确认的事实。
- 模板和参考表仅用于人工查看或手工编辑；Skill 不导出文件、不填充模板，也不声称已处理文件。
- 交付是对话内的指导包：诊断、岗位匹配、可复制正文、待确认清单、招聘者审核和版式建议按需提供。
