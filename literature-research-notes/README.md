# 论文精读笔记（literature-research-notes）

按一次研究目的读**用户给出的一篇正文**，用学生速读或精读模板写出研究问题、方法、数据、结论和局限。笔记写在对话里。

## 适用

- 用户粘贴了章节或句子，或当前对话里已经能读到论文文件。
- 用户要速读、精读、做笔记，或只核对某一个数。

## 用法

调用名：`$literature-research-notes`。说明阅读目的，并粘贴正文或给出可读文件。

与读论文无关的请求会先简短回答，再用一句说明：可以粘贴正文做速读、精读，或核对某一个数。

粘贴句里已经写明数字、单位、分母和表/节位置时，按该句写入数据或核对，不必再要图表截图。

## 输入与输出

- 输入：研究目的，加上正文、小节或已经打开的文件。
- 输出：速读（最多半页，三条写完即停）或精读（问题 / 方法 / 数据 / 结论 / 局限 / 摘录 / 阅读范围）。摘录和关键数字都要带来源位置。回复里只留笔记或说明，不写思考过程。

## 限制

- 只有题目、摘要或链接时停止，请用户粘贴后再写。
- 不打开论文链接或网页去补正文，不下载 PDF、代码或权重，不新建 `research/` 资料库。
- 不写系统综述检索式，不给论文打分。
