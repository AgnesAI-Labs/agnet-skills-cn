# 简历工作流

将简历事实核验、内容优化、可编辑母版与按 JD 定制串成一个安全的求职简历流程。

## 使用场景

- “帮我从旧简历做一份可编辑的求职简历。”
- “先整理我的经历，再针对这份 JD 做一版投递简历。”
- “我需要保留母版，并为不同岗位维护多个版本。”

## 协作关系

本包编排 `resume-content-optimization`、`resume-builder` 和 `jd-tailorer`；可编辑 Word、PDF 和渲染预览分别由已配置的 Office 转换与渲染能力实际执行后交付。
