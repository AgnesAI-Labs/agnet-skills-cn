# 个人健康记录

技术标识：`personal-health-notes`  
版本：1.4.0

在一次对话里，把你自己说过的血压、血糖、体重、用药时间、睡眠、饮食、运动和症状原话整理成健康流水。要看病时，可以说「请整理给医生」，得到一份只含这些原话的就医准备单。

调用时在前面加上 `$personal-health-notes`。

## 适合这样用

- `$personal-health-notes 今天早上 8 点血压 128/82 mmHg。`
- `$personal-health-notes 请整理给医生。`

## 输入与结果

你提供自己的原话。技能返回本次流水。你要求整理给医生，并且已经有可确认的原话时，再返回就医准备单。

## 它不会做的事

不判断是否患病，不建议改剂量，不写急救步骤，不处理儿童或宠物诊疗。紧急情况只会提示你联系医生或当地紧急服务。

记录只留在当前对话的回复里，不写文件。换一场新对话需要把内容再说一遍。
