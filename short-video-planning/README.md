# 短视频策划 Skill

- **Skill 名称：** 短视频策划
- **包名：** `short-video-planning`
- **版本：** 1.0.2
- **类型：** 独立通用 Skill
- **许可证：** MIT，全文见根目录 `LICENSE`。
- **运行依赖：** 无强制 MCP、账号或外部服务依赖。

## 用途

帮助个人创作者、企业品牌、商家和内容团队完成短视频账号的前期策划：账号定位、人设与表达风格、内容支柱、栏目/系列框架、单条视频创意简报，以及基于文字资料的账号方案诊断。

典型调用：`$short-video-planning 帮我为本地烘焙店确定短视频账号定位和三个长期栏目。`

## 使用边界

本 Skill 不读取或分析原始视频画面、音频或字幕；不负责批量选题与发布日期排期、完整逐字脚本/分镜、平台发布或私有后台采集。它会把已确认的定位、内容支柱和创意约束整理成可供排期或脚本阶段继续使用的简报，但不会声称已调用其他 Skill。

本包基于用户提供的 `short-video-planning` v1.0.0 整理为 Agnes 适配版。1.0.1 补充 MIT 许可证、版本与作者元数据、相邻 Skill 路由边界和用户说明；1.0.2 将自然触发范围收紧为短视频账号从零定位或方向重构，避免与具体选题和排期任务混淆。
