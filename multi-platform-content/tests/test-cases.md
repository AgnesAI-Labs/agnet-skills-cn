## 功能验收

| ID | 用户输入 | 期望 |
| --- | --- | --- |
| TC-F01 | 年轻人周末独处，发小红书，无现成文案，从选题到正文标题配图都做 | 不索要原稿；完整笔记；非第一人称假体验 |
| TC-F02 | 附产品介绍，做小红书、公众号、LinkedIn，要平台差异 | 提取资料重点；三版结构/开头/形式不同；不超出资料事实 |
| TC-F03 | 已有产品介绍，先查表达问题再优化，并给三个风格标题 | 先诊断再改；保留原意；三标题 |
| TC-F04 | 30 秒柿子产品视频；素材=柿子实拍图和产品视频 | 创意+分镜+口播+字幕+画面+封面+配文；不编素材外产品信息；不称视频已生成 |
| TC-F05 | 小红书多图：新手如何开始养猫；封面、每图主题文字、正文、标题、标签 | 页序连贯的完整规划 |
| TC-F06 | 同一产品五条不同角度小红书 | 五条切角和结构可区分，不是换词 |
| TC-F07 | 给品牌介绍和历史稿，按风格写新产品介绍，不照搬 | 先归纳风格再原创 |
| TC-F08 | 中文产品介绍改编为 LinkedIn 英文 | 非逐字译；专业社交语体；事实不变 |
| TC-F09 | 上一稿太像广告，改成真实用户分享，减营销感，保留产品核心 | 继承事实；只改语气；不索要全部资料 |
