# 内容形式制作指南（按需读取）

不要全套产出。用户点名什么做什么；未点名时用可直接使用的最简形式。

## 1. 社交媒体图文

最小成品：标题 + 完整正文 + 必要标签。可选：图上文字、配图规划（标明素材状态）。

仅主题：通用非第一人称。产品稀缺（B档）：每平台最多 3 句短复述，抖音只给口播句、不要分镜动作；不写使用场景故事。

## 2. 多图轮播

最小成品：封面、每页主题与文案、顺序、结尾引导、配套 Caption。用 `templates/carousel.md`。每页一个重点，页间有承接。

## 3. 短视频

最小成品（C档）：**创意一句话 + 开场 + 完整口播 + 分镜 + 字幕 + 封面文案 + 发布文案**。B 档产品事实不足时只要口播一句，不要编未给的折叠步骤或分镜动作。时长为创作估算。素材里没有的产品动作不要写进分镜当已发生。

## 4. 长视频

最小成品：主题、章节结构、完整脚本、分章画面建议、结尾。信息密度匹配预估时长，不注水。

## 5. 产品宣传视频

先列已给卖点顺序，再镜头与口播。禁止从卖点推导未提供的结构、自动化或效果。无实拍则分镜标「待拍」。

## 6. 知识科普

问题 → 解释 → 例子（须来自用户或标明示意）→ 适用限制 → 总结。不写营销口号。

## 7. 活动宣传

只用已给的时间、地点、规则、对象。缺项 `[待确认]`。角度可以是预热/正式/回顾，但事实同一底座。

## 8. 个人分享

只用用户提供的经历与素材组织叙事和情绪。没有亲历就按「仅主题」写通用文，不用第一人称假体验。

## 9. 公众号 / 博客

标题 + 导语 + 分节正文 + 结尾。论据标「已有来源 / 待核实」。

## 10. 多语言

先定目的语和地区。按目标平台重组句子和术语；专有名词、数字、限制与原文一致。不填未核验的节日或法规。

## 附加元素

- 标题备选默认最多 3 个。
- 标签相关即可。
- 封面文字短，不重复长正文。
- CTA 可选，不强制购买。
- 视觉三类状态见 `references/visual-planning.md`。
