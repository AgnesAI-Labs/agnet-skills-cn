# 批量内容与文件交付字段规范

本规范保留原技能的三类 Excel 交付能力，但仅在用户要求**文件、批量处理、跨团队交接或素材包**时启用；只要单篇文案时不要导出三个工作簿。

## 内容编号

`C001`、`C002` 等标识独立主题/成品，`C001-XHS`、`C001-DY` 标识平台版本。跨工作簿保持同一 `内容ID` + `平台` 对应关系。

## 推荐工作簿 A：分平台标题正文表.xlsx

| 列名 | 含义 |
| --- | --- |
| 内容ID | 统一编号 |
| 平台 | 小红书/抖音/公众号/Instagram 等 |
| 内容形式 | 笔记/文章/口播/轮播/短帖等 |
| 目标受众 | 从用户输入提取，未知填“未指定” |
| 主题/切角 | 此版本切入方式 |
| 标题 | 可直接使用的主标题 |
| 备选标题 | 有需要时填写，不强制 |
| 正文/口播 | 完整成品文字，不要只写摘要 |
| 封面文案 | 适用时填写 |
| 行动引导 | 有明确需求时填写 |
| 事实/来源备注 | 核心出处与待核验事实 |
| 状态 | 草稿 / 待确认 / 已校对（不表示已发布） |

## 推荐工作簿 B：话题标签表.xlsx

`内容ID | 平台 | 标签/关键词 | 使用目的 | 热度核验状态 | 备注`

每标签一行便于筛选；「推荐」不等于实时热门。无法核验时标注 `未核验`，不可写成已核实的热门标签。

## 推荐工作簿 C：素材尺寸与发布前检查表.xlsx

建议拆为两个工作表：

**素材清单**：`内容ID | 平台 | 素材类型 | 关联段落/镜头 | 建议画面或文案 | 文件名/实际路径 | 素材状态（已生成/用户提供/仅建议） | 规格/尺寸 | 规格核验状态 | 来源/核验日期 | 版权/授权状态 | 备注`

**发布前检查**：`内容ID | 平台 | 检查项 | 检查结果（通过/待核实/不适用/需修改） | 证据或备注 | 责任人（可空）`

注意：没有原始素材文件时，不得填写假路径；未查证平台技术规格，填“待从官方平台核验”，不得虚构尺寸。

## 可选额外文件

- `视频脚本.md`：口播、镜头、字幕、素材提示；多个视频可加内容编号。
- `内容素材包总览.md`：所有平台版本索引、交付状态、待补充事项。
- `视觉制作说明.md`：封面、配图、轮播页面、素材建议。
- `发布前核对清单.md`：统一核验项。

## 导出规则

1. 用户明确要文件时，且宿主有文件制作能力，应创建可验证的真实文件。
2. 避免宏、隐藏脚本、自动执行操作；默认静态表格。
3. CSV 对含逗号/换行内容正确转义，编码建议 UTF-8（如目标软件要求可采用带 BOM）。
4. 内容较长时应设置合理换行/列宽/链接，确保人工查看可用；多平台内容不要强行截断。
5. 无文件制作工具时，直接输出可复制 Markdown 表格或 TSV/CSV 文本，明确“未生成 Excel 文件”。
6. 仅输出用户实际请求的文件，不为凑齐三本工作簿制造空文件。
