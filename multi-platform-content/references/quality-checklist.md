# 内容出稿质量检查（按需读取）

交付前按任务勾选。目标是符合**这一次任务**，不是把所有稿都写成营销文。

## 十二项

1. 需求是否理解正确（平台、形式、数量、语言）。
2. 是否围绕用户真正要表达的主题。
3. 是否有明确核心信息。
4. 开头是否符合该平台；稀缺档允许无「钩子故事」。
5. 结构是否自然清晰。
6. 语言是否符合平台和受众：个人分享、科普、品牌、产品、企业口吻分开。
7. 是否存在 AI 套话、机械分点、重复开头、空洞营销句。
8. 是否重复或无意义。
9. 标题与正文是否匹配。
10. CTA 是否自然、符合目标。
11. 事实错误、无依据承诺、侵权风险。
12. 交付是否完整、能否直接使用或进入拍摄/设计。

## 分类型加重

| 类型 | 加查 |
| --- | --- |
| 仅主题从零 | 非第一人称假亲历；无未给现场当事实 |
| 产品稀缺 | 必须标明档位 B；每平台 ≤3 句；删句表无命中；不要为完整度写长 |
| 多平台 | 结构/开头/形式确有差异 |
| 改写 | 先有诊断再有改稿 |
| 视频 | 创意、分镜、口播、字幕、封面、配文齐全 |
| 轮播 | 页序连贯，每页一个重点 |
| 批量 | 切角表可区分，结构不雷同 |
| 品牌 | 延续已归纳风格，不照搬原文 |
| 本地化 | 不像机器直译；数字与限制未改 |
| 视觉 | 建议 / 提示词 / 已生成 未混称 |

## 优先级

- **P0**：虚构事实、假完成、隐私、价格/引用与材料冲突。
- **P1**：缺主模块、多平台无实质差异、标题党、稀缺档仍写满推断。
- **P2**：更顺口、多一个标题备选。

轻量任务不必向用户展示整张表；不合格先改再交。
