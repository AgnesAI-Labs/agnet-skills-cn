# 平台内容适配指南（按需读取）

表达策略，不是保证审核通过的规格手册。字数、时长、尺寸、标签、广告标识会变：能查官方则写日期；不能则标「发布前待核对」，不编造数字。

用户点名哪个平台，只深做哪个。下面「原生交付」是默认主形式，用户另指定形式时服从用户。

## 国内

### 小红书
- 主形式：图文笔记；也可多图轮播、短视频。
- 结构：具体场景或问题 → 可执行细节 → 收束。稀缺事实档改为短复述，不编场景。
- 标题/开头：信息具体，避免「震惊体」。
- 正文与标签：分段易扫；标签与主题相关，不标热度。
- 视觉：封面文案短；多图每页一个点。
- CTA：收藏/评论自然提问，不强制购买。
- 类型：个人分享用非营销口吻；产品仅用已给卖点。
- 限制：商单标识、尺寸以当期后台为准。

### 微信公众号
- 主形式：长图文。
- 结构：标题与导语点明论点 → 分节 → 总结或下一步。
- 标题/开头：承诺与正文一致，不标题党。
- 正文：小标题、引用可追溯；不编专家和数据。
- 视觉：标明插图位置与状态。
- CTA：阅读相关、关注需符合账号习惯，不硬推销。
- 类型：知识文重解释边界；活动文只写已给时间地点规则。
- 限制：原创声明、引用规范以平台当期规则为准。

### 微博
- 主形式：短帖；可线程。
- 结构：信息前置，一句观点或一事。
- 标题：通常无独立标题，首句即钩子。
- 正文/话题：精炼；话题词不冒充热搜。
- 视觉：单图或视频封面建议，状态分开写。
- CTA：讨论点或提问。
- 类型：观点、通知、短体验（须有用户经历才用第一人称）。
- 限制：字数与超话规则待核验。

### 抖音
- 主形式：短视频（口播+分镜）；用户要图文则做图文。
- 结构：前几秒问题或演示 → 展示已知信息 → 收束。
- 开头：画面或字幕先说明「这是什么」。
- 描述/标签：短，与内容一致。
- 视觉：分镜、字幕、封面文案；无素材不编动作细节。
- CTA：评论问题，不承诺推荐机制。
- 类型：演示须用户有或将拍的画面；知识口播可纯讲解。
- 限制：时长、封面、广告标识待核验。

### B站
- 主形式：中长视频；也可短视频。
- 结构：问题 → 章节 → 示例 → 结论。
- 标题/开头：说清观众能获得什么。
- 简介/标签/章节：与脚本一致。
- 视觉：章节画面建议；素材授权单列。
- CTA：订阅/收藏按用户身份，不编播放数据。
- 类型：教程、科普、产品拆解（事实充足时）。
- 限制：封面、分区、音乐版权待核验。

### 知乎
- 主形式：问答长文。
- 结构：先答问题 → 论据 → 适用边界 → 总结。
- 开头：直接给判断或方法。
- 正文：事实与个人判断分开；无来源不编论文。
- 视觉：示意图建议可选。
- CTA：补充讨论，不硬广。
- 类型：经验须用户提供经历；否则写通用方法。
- 限制：商业推广规范待核验。

### 微信视频号
- 主形式：短视频。
- 结构：社交场景下先说对人有什么用 → 口播/镜头 → 互动。
- 描述/封面文字：短。
- 视觉：竖屏构图建议。
- CTA：转发或私信仅当用户要求且不编效果。
- 限制：尺寸时长按当期版本核验。

## 国际

### LinkedIn
- 主形式：专业短帖或文章。
- 结构：洞察或结论开篇 → 背景 → 方法/启发。英文默认职业社交语体。
- 开头：避免国内营销口号直译。
- 正文：短段；不编业绩、客户名、增长数字。
- 视觉：简报式配图建议。
- CTA：讨论问题或「了解更多」资料链接占位。
- 本地化：术语用目标行业英语，不逐句翻译中文排比。
- 限制：广告与数据声明待核验。

### Instagram
- 主形式：Feed 图文、Carousel、Reels。
- 结构：画面主题先行，Caption 补充。
- 开头：Caption 首行可检索。
- 视觉：色调一致；Carousel 见轮播模板。
- CTA：bio/链接按用户是否提供。
- 限制：比例、Reels 时长待核验。

### TikTok
- 主形式：短视频。
- 结构：清晰 hook → 短步骤或情境 → 收尾。
- 视觉与字幕：关键信息印在画面上。
- 标签：相关即可，不编 trending 证据。
- 限制：音乐、挑战、时长待核验。

### YouTube
- 主形式：长视频；Shorts 另标。
- 结构：价值承诺 → 章节 → 演示 → 回顾。
- 标题/简介/缩略图文案：与内容一致。
- 视觉：章节画面；不编已上传视频。
- 限制：版权音乐、缩略图规格待核验。

## 其它

快手、X 等：按用户描述的受众与形式做，无资料时不编平台规则。

## 适配原则

1. 一个事实底座，多种呈现；禁止一稿换平台名。
2. 平台 × 形式共同决定，不把平台锁死为单一体裁。
3. 不用每个平台都套「必看/收藏起来」。
4. 海外做本地化，不搬国内梗当事实。
5. 品牌名、时间、价格、功能范围跨平台一致。
