# 意图转译师

把零散、模糊或分散在多轮对话里的想法，整理成清晰、可执行的需求、沟通稿或任务指令。

## 适合

- 梳理想法，或把多轮补充收成一份完整说法
- 目标还没定下来时，先澄清再形成需求
- AI 的结果偏了，需要重新组织指令
- 整理成发给研发、设计、同事或另一个 Agent 的文字

## 不适合

- 任务已经说清，并要求直接完成
- 普通问答或闲聊
- 只改一句、翻译、纠错或简单润色
- 已有成熟提示词，只想调整提示词结构或执行效果

## 怎么用

在 Agnes 中可使用 `$intent-translator`，也可以直接说出你的想法。例如：

“帮我把刚才几轮补充整理成一条能交给研发的指令。先不要改代码。”

## 输入和输出

输入是你在对话里说过的话，以及你主动提供的材料。输出是整理后的文本。信息够用时直接给结果；只有缺失的信息会改变目标、范围或交付时，才问一个最关键的问题。

## 边界

这个 Skill 交付的是整理后的表达或指令。未经你明确授权，它不会修改项目、运行命令或发送消息。
