# 交付物与字段约定

仅在用户的任务规模、格式要求或工具能力需要时生成文件。优先支持简洁交付，不要把所有字段塞进用户只要求的三条选题。

## 1. 内容选题池（优先 .xlsx；兼容 .csv / Markdown）

推荐文件名：`内容选题池.xlsx`。推荐列：

| 字段 | 类型/取值 | 说明 |
| --- | --- | --- |
| 选题ID | 文本，如 T-001 | 已有表优先保留原 ID |
| 栏目/系列 | 文本 | 可空 |
| 选题主题 | 文本 | 面向用户的具体选题 |
| 内容角度/承诺 | 文本 | 回答什么问题、提供什么价值 |
| 目标受众/场景 | 文本 | 读者/观看者具体是谁 |
| 内容形式 | 枚举/文本 | 图文/短视频/文章/长视频/直播等 |
| 建议渠道 | 文本 | 可多个，用分号隔开 |
| 选题来源类型 | 枚举 | 用户资料/已核实外部资料/策划假设 |
| 依据/来源说明 | 文本 | 文档名、记录描述、链接或“待验证” |
| 优先级 | 高/中/低 | 按任务需求可增加评分列 |
| 制作难度 | 低/中/高 | 粗略判断，不假装精确工时 |
| 状态 | 候选/待确认/已选定/制作中/已完成/已取消 | 生命周期 |
| 下一步动作 | 文本 | 例如补素材、约访谈、写提纲 |
| 备注 | 文本 | 限制条件、依赖 |

**最小对话版**可以只保留：选题、角度、受众、优先级、理由。

## 2. 内容发布日历

推荐文件名：`内容发布日历.xlsx`。推荐列：

| 字段 | 类型/取值 | 说明 |
| --- | --- | --- |
| 排期ID | 文本，如 P-001 | 不同平台动作分别编号 |
| 选题ID | 文本 | 关联选题池，可一个选题对应多条排期 |
| 计划发布日期 | `YYYY-MM-DD` 或相对周次 | 不确定时不伪造日期 |
| 发布渠道 | 文本 | 平台/媒介 |
| 栏目/系列 | 文本 | 可空 |
| 内容主题 | 文本 | 与选题池保持一致 |
| 内容形式 | 文本 | 图文/短视频/文章等 |
| 制作负责人 | 文本 | 未知写“待定” |
| 制作截止日期 | `YYYY-MM-DD` 或相对节点 | 不能晚于发布日期（特殊情况注明） |
| 审核/复核节点 | 文本/日期 | 没有审核则“无需” |
| 状态 | 待准备/制作中/待审核/待发布/已发布/延期/取消 | 保留原始状态 |
| 依赖/风险 | 文本 | 素材、授权、外部信息或待确认项 |
| 备注 | 文本 | 包含相关约束 |

**最小对话版**：日期/周次、主题、渠道、负责人、状态。

## 3. 可选输出

- `系列内容规划.md`：系列定位、目标、受众、期数、顺序、每期价值和相互依赖。
- `内容执行清单.xlsx`：任务ID、选题ID、任务、负责人、起止时间、依赖、状态。
- `排期调整记录.md`：排期ID、原日期、修改日期、原状态、新状态、变更原因、影响范围。
- `内容规划建议.md`：主目标、内容支柱、推荐选题、运营假设、风险、下一步行动。

## 4. 文件格式与质量

- 默认面向中文用户提供中文表头；使用其他语言时改为对应语言，不混用。
- 用户明确要 Excel 且工具支持，优先输出真正的 `.xlsx`，不是重命名的 CSV。没有能力时清楚说明，输出兼容 CSV 或 Markdown。
- `.xlsx` 有条件时：首行固定表头、筛选、冻结首行、合理列宽、长文本换行、优先级和状态下拉项（能实现时）；保持内容可编辑。
- `.csv` UTF-8 with BOM 可改善部分中文 Excel 环境导入表现；字段内换行或逗号必须按 CSV 规则引用。
- 日期字段使用 ISO 格式，避免“下周三”在导出后失去上下文；仅相对日期时使用明确周次并注明基准未给出。
- 永不创造不存在的事实来源。URL 只在实际有来源时填写。
- 不包含真实个人身份、手机号、账号密钥等敏感内容，除非用户明确授权且确属任务必要。
- 用户提供原文件时，先确认文件结构、字段类型和计划锁定约束；保留原字段、数据和 ID，不删除旧表痕迹。
- 正式表必须：选题ID/排期ID 唯一；日历每行有对应选题ID；能发现重复键、空日期、同一渠道同日冲突。
- 独立会话没有源计划时，不要编造四周数据来凑 Excel 或 CSV。说明限制后只给空表头，或等待用户粘贴。不得用「示例假设」选题把用户要导出的计划表填满。
