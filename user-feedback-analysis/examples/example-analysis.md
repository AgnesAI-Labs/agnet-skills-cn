# 演示分析（完全虚构数据，不代表真实用户调研）

**数据：** `examples/synthetic-feedback.csv`，12 条虚构课程平台评论，日期均为虚构。此处**只演示主要主题单标签编码**；实际 Skill 应允许一条反馈多个主题。

## 结论速览

1. **播放/加载**为本次最多的负面问题主题，12 条中有 3 条涉及（F004、F005、F010），其中 F010 描述更新后无法打开课程，严重度可能更高，建议优先复现故障。
2. **导航/作业入口**有 2 条（F001、F009），两条都说提交作业的入口难找，可检查入口层级和任务路径。
3. **正向反馈**共 3 条（F002、F008、F012）：2 条肯定课程讲解，1 条肯定试听体验，值得保留。
4. 另有 **字幕可读性、学习进度、学习路径、自测练习**各 1 条，属于具体改进线索；单凭这些记录不能证明问题普遍存在。
