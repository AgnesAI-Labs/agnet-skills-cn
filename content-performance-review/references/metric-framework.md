# 指标框架与口径规则

## 1. 指标选择顺序

先明确内容目标，再选择主指标、辅助指标和护栏指标。常见目标与指标关系如下：

| 目标 | 可选主指标 | 辅助/护栏指标 | 注意事项 |
|---|---|---|---|
| 扩大触达 | 触达人数、曝光量 | 频次、目标受众占比 | 曝光量不等于独立人数 |
| 提升观看 | 播放量、有效观看人数 | 平均观看时长、完播率 | 不同平台的播放起算规则可能不同 |
| 提升阅读 | 阅读量、阅读完成 | 停留时长、收藏、分享 | 阅读量、打开量和独立读者可能不同 |
| 提升互动 | 评论、分享、收藏、互动人数 | 负面反馈、互动质量 | 互动总量需结合触达规模解释 |
| 获取关注 | 新增关注、关注转化 | 取关、主页访问 | 明确关注归因窗口与来源 |
| 获取点击 | 链接点击、按钮点击 | 点击后跳出、有效访问 | 区分点击次数与点击人数 |
| 获取线索 | 有效线索数、线索转化率 | 线索质量、无效线索率 | 明确线索定义与去重规则 |
| 获取注册/购买 | 注册数、订单数、收入 | 转化率、退款、客单价 | 需要可靠归因和观察窗口 |
| 提升投放效率 | CPM、CPC、CPA、ROAS | 频次、质量、转化周期 | 仅在成本和归因数据齐全时计算 |
| 建立认知/信任 | 品牌搜索、正向反馈、调研指标 | 触达、评论主题、认知变化 | 不能仅凭点赞推断品牌认知提升 |
| 社区参与 | 有效讨论、回复深度、UGC | 活跃参与者、问题解决率 | 区分灌水互动与有效贡献 |

## 2. 通用字段字典

字段映射应保留原始列名。下表仅为语义参考，不表示各平台定义相同。

| 通用字段 | 含义 | 典型单位/注意事项 |
|---|---|---|
| `impressions` | 内容展示次数 | 次；同一人可多次展示 |
| `reach` | 触达的独立用户数 | 人；平台定义可能不同 |
| `views` | 播放/观看次数 | 次；播放起算门槛可能不同 |
| `unique_views` | 独立观看人数 | 人；不等于播放次数 |
| `watch_time` | 总观看时长 | 秒/分钟；统一单位 |
| `avg_watch_time` | 平均观看时长 | 秒；确认分母是播放还是观看人数 |
| `completion_rate` | 完播率 | %；确认完播定义和统计口径 |
| `likes` | 点赞数 | 次/人，按平台定义 |
| `comments` | 评论数 | 条；必要时区分有效评论 |
| `shares` | 分享数 | 次/人，按平台定义 |
| `saves` | 收藏数 | 次/人，按平台定义 |
| `clicks` | 点击次数 | 次；区分链接、卡片、主页等点击 |
| `follows` | 新增关注 | 人；确认归因来源和时间窗口 |
| `leads` | 线索数 | 条/人；需定义有效线索 |
| `registrations` | 注册数 | 人；需确认去重和归因窗口 |
| `purchases` | 购买/订单数 | 笔/人；明确订单与用户口径 |
| `revenue` | 收入 | 币种、税费、退款口径需明确 |
| `spend` | 投放成本 | 币种、含税与否、归属周期需明确 |
| `duration` | 内容时长 | 秒；仅适用于有时长的内容 |

## 3. 常见衍生指标

只有分子、分母均可确认且处于相同统计范围时才计算。

| 指标 | 常见计算方式 | 必须注明的事项 |
|---|---|---|
| 互动总量 | 点赞 + 评论 + 分享 + 收藏（按可用字段） | 是否包含其他互动；是否重复计数 |
| 互动率 | 互动量 ÷ 触达人数，或互动量 ÷ 曝光量，或互动量 ÷ 播放量 | 明确采用哪个分母；不可混用 |
| 点击率 CTR | 点击次数 ÷ 曝光量，或点击次数 ÷ 触达人数 | 采用的曝光/触达口径 |
| 关注转化率 | 新增关注 ÷ 主页访问，或新增关注 ÷ 触达人数 | 归因窗口与分母定义 |
| 完播率 | 完播次数 ÷ 有效播放次数 | 平台完播和有效播放定义 |
| 平均观看时长 | 总观看时长 ÷ 播放次数，或平台给定值 | 确认分母及重复播放处理 |
| 点击后转化率 | 转化人数 ÷ 点击人数 | 确认点击和转化是否同一人群/窗口 |
| CPM | 成本 ÷ 曝光量 × 1000 | 币种和曝光口径 |
| CPC | 成本 ÷ 点击次数 | 点击类型和成本归属 |
| CPA | 成本 ÷ 转化数 | 转化事件定义和归因窗口 |
| ROAS | 归因收入 ÷ 广告成本 | 收入范围、退款、归因窗口 |

**禁止事项：** 不要将不同分母的“互动率”合并成一个字段；不要把百分比格式的 0.2 与 20 混淆；不要在分母为 0 或缺失时生成 0% 作为结果。应标记为“不适用/无法计算”。

## 4. 平台差异与跨平台比较

不同平台可能对曝光、播放、触达、阅读、互动、点击、粉丝增长等采用不同定义。执行跨平台分析时：

1. 保留来源平台和来源字段；
2. 记录每个平台的原始定义（若用户提供或可从授权资料确认）；
3. 为可比字段建立映射等级：可直接比较、需谨慎比较、不可比较；
4. 对不可比较指标分别展示，不求和、不做统一排名；
5. 如需综合观察，使用平台内相对表现，例如相对本平台同类内容中位数、平台内分位或目标完成率；
6. 明确相对分数不是平台间的绝对效果等价。

## 5. 时间窗口和内容生命周期

- 内容发布后累计数据必须注明截至日期和观察天数。
- 对比内容时，尽量使用相同发布后观察窗口，例如发布后 7 天；若无法统一，标记差异。
- 平台后台的自然累计值与固定周期值不可混为一谈。
- 对长尾内容，短期数据可能低估后续表现；对热点内容，早期数据可能更有代表性。
- 如果数据是每日快照，先判断是当日新增还是累计值，避免重复累加。

## 6. 目标与基准

基准优先级：

1. 用户明确提供的目标值或 KPI；
2. 同一账号、同一平台、同类内容、相近观察窗口的历史数据；
3. 本批次内部的中位数、分位数或同类组对照；
4. 用户提供的外部行业基准。

未提供可靠基准时，不编造“行业平均”。可以说“在本批样本中高于/低于中位数”，不要说“行业表现优秀”。

搜索摘要、社区文章、代运营经验和未附官方链接的网页数字不是基准。没有用户给出的基准，也没有写明链接和核验日期的平台官方定义时，不输出任何行业百分比、流量池门槛或优质区间。

## 7. 平台官方定义核验

平台指标会随产品形态、统计规则和时间更新。实际复盘时优先使用用户提供的后台导出说明或平台官方帮助文档；若可联网且当前定义会影响结论，应核对官方来源并记录访问日期。不要把某一平台的指标定义推广到其他平台。

以 YouTube 官方 Analytics 指南为例，视频分析会区分曝光、曝光点击率、观看量和平均观看时长，并建议将同一内容形式进行比较，因为不同形式的受众行为和目标可能不同。此例只用于说明“按内容形式分组”的必要性，不构成其他平台的通用指标口径：

- YouTube 内容表现与内容形式分析：https://support.google.com/youtube/answer/12942217
- YouTube 内容分析指标说明：https://support.google.com/youtube/answer/12220281

核验时记录：平台/产品形态、指标原名、官方定义、统计范围、分子/分母、是否独立人数、观察窗口、更新时间或核验日期。
