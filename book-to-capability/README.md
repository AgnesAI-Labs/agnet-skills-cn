# book-to-capability

把书籍、论文、课程资料或专业报告里的知识，按你要完成的真实任务，做成原创、可执行、可复用的 AI 能力或 Skill。

这个技能不写读书摘要，也不复刻原书的表达、案例或章节结构。

## 适用场景

- 根据一本书或一份资料，设计解决具体问题的 AI Skill。
- 把资料中的方法、模型和判断规则，转成 AI 可以执行的工作流程。
- 综合多份论文、课程或专业报告，构建一项领域能力。
- 检查已有 Skill 是否真正用上了指定知识，并给出优化方案。

只想要读书摘要、书评或按章节梳理时，直接说明即可。本技能不会把这类请求擅自改成 Skill 开发。

## 怎么调用

在 Agnes 中可以输入：

```text
$book-to-capability
```

也可以直接用自然语言提出需求，例如说明你有哪份资料、希望 AI 完成什么任务。

## 输入与输出

建议同时提供：

- 希望 AI 完成的具体任务；
- 谁会使用、在什么情况下使用；
- 书籍或资料正文，或你能提供的章节摘录；
- 期望的输入、输出，以及怎样算完成。

目标还不清楚时，可以先描述遇到的问题。

按当前进度，结果会是下面之一：

- 能力方案：目标、资料实际读到的范围、与任务相关的知识、取舍、原创执行方式，以及风险和待确认事项。
- 完整 Skill：可保存的 `SKILL.md`、`README.md` 和 `LICENSE`，并说明知识来源与版权边界。
- 对已有 Skill 的修改意见：必须改的问题、可以稍后改的地方，以及不必为了塞入知识而改动的部分。

只有书名、没有正文时，不会把没读到的内容写成已经读过。
