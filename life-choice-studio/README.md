# 人生决策推演室

Agnes 对话用的人生决策推演 Skill，调用标识为 `$life-choice-studio`（内容版本 1.11）。材料够时首轮给临时判断与决策卡；答卡后通常进入路径比较与条件性结论。危机／心理相关场景只给短求助。

## 适用场景

- 两份工作机会、要不要争取项目
- 是否换城市、转行或暂停一段时间
- 课程、技能或职业转换是否值得投入
- 结婚、带小孩、家庭与生活安排中的一般性取舍

## 调用示例

- “我拿到上海大厂和本地小公司的 offer，五天内要答复，怎么选？”
- “我该不该从成都搬去杭州发展？”
- “要不要现在结婚？孩子和同城还没谈拢。”
- “要不要全职带小孩两年？”
- “组里有个高曝光项目，要不要争？”

## 输出内容

1. 首轮：临时判断（当前倾向／关键假设／反转信号）+ 决策卡；
2. 答卡后：2–3 条路径的近期／中期／失败条件／转向信号；
3. 条件性结论与 1–3 个可自行执行的下一步；
4. 用户要求时再展开更完整的推演档案。

## 默认互动方式

默认先给每轮 1–2 道选择题，你可以直接回 `1A 2C`。开场只作短复述，不先堆长文。信息够用且你要判断时，会先给带假设的临时判断，再补最关键的一张卡。只有你明确要求深聊时，才改用开放问题。

## 边界

不替用户作最终决定，也不提供具体医疗诊断或治疗、法律案件结论、证券投资买卖指令。遇到即时危险、自伤自杀、轻生念头、暴力或胁迫时，只给极短求助提醒，并且不向你提问。提及可能的抑郁等问题时，先建议专业支持，不做症状筛查，不把危机改成普通上学／职业选择题。普通选择题会用固定的「临时判断 + 决策卡」格式回答，不会只重复你的原话。

默认只根据当前这道题里你提供的信息做比较。没有你给出的文件路径时，不会在电脑里搜索简历或其他文件；需要时请你粘贴或提供一个路径。不会代你发消息、报名、签约或付款。没有你给出或核对过的房租、薪资等数字，不会被写成具体金额。

本 Skill 不设置额外数据接收方。对话由所使用的平台处理，保存与删除规则以平台说明为准。需要下次继续时，可以要求生成一段摘要并自行保存。
