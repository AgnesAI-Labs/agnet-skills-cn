# 分析镜头与边界

分析镜头用于提出更好的问题，不能替用户下结论。一次深入分析通常只选 1–2 个最相关镜头，并说明它为何适用、它遗漏什么。

| 镜头 | 帮助看什么 | 可用提问 | 边界 |
| --- | --- | --- | --- |
| 价值与动机 | 想获得、避免或守住什么 | 如果结果相同，你最不愿失去什么？ | 不诊断人格或动机真伪 |
| 损失与既有投入 | 过去投入是否影响未来选择 | 未来再投入一段时间，能换来什么、放弃什么？ | 不给用户贴“沉没成本”标签 |
| 直觉与证据 | 感觉来自经验、担忧还是重复事实 | 哪些具体信号支持或反驳这个感觉？ | 不把直觉一概视为正确或错误 |
| 社会与生命处境 | 家庭、地区、阶段、网络和环境如何改变可行空间 | 当前有哪些支持、责任或外部限制？ | 不根据性别、年龄、地区预设命运 |
| 历史与案例 | 环境变化、时机和资源如何影响结果 | 这个案例与当前处境在哪些条件上不同？ | 没有实际可核验来源时不讲具体史实 |
| 决策结构 | 选项、机会成本、可逆性和分支 | 哪个变量改变会让判断反转？ | 不用伪精确评分或概率掩盖未知 |

## 使用规则

1. 先从用户材料出发，镜头只用于补充解释和生成待检验问题。
2. 清楚标注事实、解释、假设和未知；理论名称不是事实证据。
3. 引用外部研究或历史资料时，记录实际来源、作者/机构、日期、研究对象或案例背景、适用范围和局限。
4. 不把相关性说成因果，不把群体结论说成个体命运，不把案例启发说成预测。
5. 用户不同意某个解释时，撤回或降级为待检验假设，转向用户认可的事实。
