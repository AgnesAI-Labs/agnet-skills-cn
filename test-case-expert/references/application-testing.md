# 软件应用测试（Web / 桌面 / 移动端）

## 测试范围

### 页面与视觉
- 页面加载、布局、内容、组件状态；
- 不同窗口尺寸、缩放、横竖屏；
- 字体、图标、颜色、溢出、遮挡；
- 空状态、加载状态、错误状态；
- 多语言、日期、数字和时区展示。

### 交互
- 按钮、链接、菜单、弹窗、下拉框、标签页；
- 输入、校验、清空、提交、取消；
- 键盘操作、焦点顺序、快捷键；
- 禁用、加载中、防重复点击；
- 页面跳转、返回、刷新、深链接；
- 拖拽、上传、下载、复制粘贴。

### 账号、会话和权限
- 注册、登录、退出、密码重置；
- 会话保持、过期、刷新；
- 不同角色的可见性和操作权限；
- 未授权访问、越权访问；
- 多账号切换和会话隔离。

### 数据与业务
- 创建、读取、更新、删除；
- 保存后刷新是否保留；
- 切换页面/会话后的数据状态；
- 搜索、排序、筛选、分页；
- 重复提交、并发修改、数据冲突；
- 导入导出和文件内容正确性。

### 安装与升级（桌面/移动端）
- 首次安装、覆盖安装、升级、降级（如支持）；
- 权限申请、系统弹窗、启动和退出；
- 配置、缓存和用户数据保留；
- 卸载残留、重装恢复；
- 不同系统版本和架构兼容。

### 兼容性
- 浏览器/操作系统/设备型号；
- 分辨率、缩放、输入法、语言；
- 网络环境和代理环境；
- 不同版本客户端与服务端组合。

### 性能与稳定性
- 首屏、关键操作响应时间；
- 长列表、大文件、大数据量；
- 长时间运行、内存增长；
- 网络波动、服务端延迟；
- 崩溃恢复、应用重启和状态恢复。

## UI 自动化用例写法
每条用例写明：
1. 环境/设备/版本；
2. 初始页面和账号状态；
3. 操作入口及逐步动作；
4. 每步预期页面反馈；
5. 最终状态和数据断言；
6. 截图/录屏/日志等证据要求。

不要只写“点击按钮，检查功能正常”。必须明确按钮位置/名称、操作后可观察结果。
