# API、接口、数据库与数据处理测试

## 一、API 测试

### 请求契约
- HTTP 方法、路径、请求头、Content-Type；
- 必填/选填参数、类型、格式、默认值；
- 枚举、长度、范围、嵌套结构；
- 编码、特殊字符和空值。

### 响应契约
- 状态码、响应头、响应体结构；
- 字段类型、必需字段、可空字段；
- 错误码和错误信息；
- 分页、排序、过滤；
- 时间、金额、精度和时区。

### 鉴权与权限
- 无凭证、无效凭证、过期凭证；
- 不同角色、资源所有者和跨用户访问；
- 最小权限和对象级授权；
- 凭证刷新、撤销和重放风险。

### 异常与可靠性
- 参数错误、资源不存在、冲突；
- 限流、超时、服务不可用；
- 重试、重复请求、幂等键；
- 网络中断、部分失败；
- 并发请求和竞态条件。

### 接口链路
- 前置接口输出是否正确传给后续接口；
- 调用顺序、依赖和状态；
- 回调/Webhook 重复、乱序和签名验证；
- 失败后的补偿和恢复。

## 二、数据库测试

- CRUD 和字段映射；
- 主键、外键、唯一约束、非空约束；
- 默认值、索引、排序和查询结果；
- 事务提交、回滚、隔离和并发更新；
- 重复、缺失、异常和超范围数据；
- 迁移前后数据一致性；
- 备份、恢复和数据保留策略。

## 三、ETL/数据流水线
- 源数据缺失、重复、乱序、格式错误；
- 清洗、转换、映射、聚合规则；
- 空值、异常值和数据类型转换；
- 增量/全量处理；
- 重跑是否重复写入；
- 断点续跑和失败记录；
- 输入与输出条数、校验和及关键字段一致性。

## 用例必须包含
- 环境和接口地址（可脱敏）；
- 方法、参数、请求体；
- 前置数据；
- 预期状态码及响应结构；
- 数据库/外部状态断言；
- 是否会产生真实副作用。

不要编造接口状态码或业务规则。若 API 文档未说明，标注待确认。
