# 测试方法来源参考

以下资料用于说明测试设计理念的参考来源，不是本 Skill 的认证声明，也不表示每个项目都必须采用其中全部过程。遇到需要符合指定标准/版本的验收任务时，应取得适用文本、确认项目范围并逐条映射；不能凭本 Skill 的通用检查清单宣称符合标准。

| 来源 | 可参考的范围 | 官方资料 |
|---|---|---|
| ISTQB CTFL | 测试基础、测试过程与设计技术的概念框架 | [CTFL v4.0.1 syllabus](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf) |
| ISO/IEC/IEEE 29119 | 软件测试概念与测试过程标准系列 | [ISO/IEC/IEEE 29119 series](https://committee.iso.org/sites/jtc1sc7/home/projects/flagship-standards/isoiecieee-29119-series.html) |
| OWASP WSTG | Web 应用/服务的安全测试场景与方法 | [OWASP Web Security Testing Guide](https://wstg.owasp.org/) |
| OpenAI agent evaluation docs | 通过运行轨迹、评分标准和评估集检查 Agent 工作流表现 | [Evaluate agent workflows](https://developers.openai.com/api/docs/guides/agent-evals) |

本 Skill 对这些主题作通用测试设计层面的整理，不复制标准正文。实际安全测试必须限定授权环境；使用某一标准或指南时应核对适用范围与版本。
