# 自动化工作流、插件、MCP 与连接器测试

## 一、触发与入口
- 触发词、事件、定时器、手动入口；
- 必要参数缺失或格式错误；
- 重复触发、并发触发；
- 未满足触发条件时是否误执行。

## 二、节点与数据流
- 每个节点输入、输出和类型；
- 上游字段是否正确映射到下游；
- 空值、字段缺失、类型不匹配；
- 条件分支、循环、合并和分流；
- 节点执行顺序和依赖；
- 大数据量和长链路。

## 三、工具、插件与 MCP
- 工具是否正确注册、发现和加载；
- 工具名称、描述和参数 Schema；
- 必填参数、可选参数、枚举和类型；
- 授权、连接、凭证和权限范围；
- 调用成功、错误返回、超时和限流；
- 工具输出是否被正确解析和传递；
- 工具不可用时是否合理提示或降级。

## 四、工作流状态
- 成功完成、失败、取消、中断；
- 超时、重试、最大重试次数；
- 断点恢复、补偿、回滚；
- 重复运行和幂等性；
- 节点失败后是否错误执行后续节点；
- 部分成功时如何报告结果。

## 五、外部副作用
- 是否发送邮件、消息或创建外部记录；
- 是否写入/删除文件或数据库；
- 是否产生重复任务或重复账单；
- 是否按授权范围操作；
- 测试环境与生产环境是否隔离。

## 六、日志与可观测性
- 是否记录运行 ID、节点、时间和错误；
- 错误是否能定位到节点/工具；
- 日志是否泄露密钥或敏感数据；
- 是否能追踪输入、输出和状态变化。

## 用例建议
至少覆盖正常链路、分支路径、缺参、工具失败、超时/重试、重复触发、权限不足、部分失败和恢复路径中最相关的场景。
