# 代码与脚本测试

## 适用对象
函数、类、模块、命令行程序、Python/JavaScript/TypeScript/Java/Shell 等脚本。

## 一、静态分析
在不运行代码的情况下检查：
- 语法、导入、依赖和路径引用；
- 参数定义、类型、默认值；
- 分支、循环、递归和异常处理；
- 文件、网络、进程、环境变量等副作用；
- 硬编码密钥、敏感信息及危险命令；
- 日志、错误信息和资源清理。

静态分析不能证明运行成功。

## 二、输入与输出
- 正常输入、最小输入、最大输入；
- 空值、None/null、空字符串、空集合；
- 类型错误、格式错误、非法字符；
- 超长文本、大文件、大数组；
- Unicode、中文、特殊字符、换行、编码；
- 负数、零、极大值、精度和溢出；
- 缺失参数、额外参数、参数顺序；
- 返回值结构、类型、退出码和标准输出/错误输出。

## 三、控制逻辑
- if/else 每个分支；
- 多条件组合；
- 循环 0 次、1 次、多次及边界次数；
- 空集合、单元素集合、大集合；
- 递归终止条件；
- 异常抛出、捕获、重试、finally/清理路径。

## 四、文件与系统资源
- 文件不存在、空文件、损坏文件、格式错误；
- 路径包含空格、中文、特殊字符；
- 相对路径/绝对路径、目录不存在；
- 只读目录、权限不足、磁盘空间不足；
- 同名文件、覆盖策略、临时文件；
- 文件写入中断、部分写入、并发访问；
- 文件句柄、连接、锁、子进程是否释放。

## 五、依赖和运行环境
- 依赖缺失、版本不兼容；
- 环境变量缺失或错误；
- 不同操作系统、Shell、Python/Node 版本；
- 网络不可用、外部服务超时；
- 时区、区域设置、字符编码；
- 工作目录变化和路径分隔符。

## 六、重复执行与可靠性
- 同一输入重复执行结果是否一致；
- 重复执行是否造成重复写入或重复副作用；
- 幂等性是否符合预期；
- 中途失败后重跑是否安全；
- 超时和中断后是否留下不完整状态。

## 七、脚本专属断言
优先检查：
- 退出码；
- 标准输出/错误输出；
- 返回对象和字段；
- 文件是否生成、内容是否正确、是否可读取；
- 数据库/外部状态是否按预期变化；
- 运行时间和资源使用（有明确阈值时）。

## 安全边界
执行脚本前先检查潜在副作用。不要在生产环境执行删除、覆盖、外发、权限修改或其他不可逆操作。优先使用隔离目录、虚拟环境、模拟数据和沙箱。
