# JD 简历定制器

针对一个具体职位描述，识别真实匹配点与缺口，先取得用户确认，再交付独立的岗位定制简历正文或文件。

## 使用场景

- “分析这份 JD，我的经历哪些匹配、哪些有差距？”
- “保留我的母版，给这个岗位做一版投递简历。”
- “先告诉我会怎么改，确认后再生成文件。”

## 输出

岗位要求地图、匹配分析、变更预览、定制正文、修改对照与待确认事项；只有上层文件能力实际执行成功时才交付 HTML、Word 或 PDF。
