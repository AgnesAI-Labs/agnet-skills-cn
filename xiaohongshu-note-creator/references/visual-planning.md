# 图文协同与视觉规划

## 1. 图文任务判断

当用户上传图片、明确要求图文规划，或图片是内容价值的重要组成部分时，执行本模块。单纯文字改写无需强行生成图文表。

## 2. 图片分析

对每张可读取图片识别主体和场景、主要细节和可见文字、清晰度与信息量、与主题的关联、是否与其他图片重复、适合承担的内容作用。不得猜测图片无法确认的信息。

## 3. 封面选择

封面应快速传达主题和阅读价值。选择时考虑主体是否清晰、是否代表整篇内容、是否有足够文字空间、缩略显示时是否容易理解，以及是否与标题和正文一致。不应只因图片漂亮就选择与主题无关的封面。

## 4. 图片顺序

可按叙事顺序（场景、过程、结果）、教程顺序（目标、步骤、细节、总结）、信息顺序（总览、分项说明、对比、结论）、体验顺序（环境、过程、细节、评价）或清单顺序（标准、条目、比较、建议）组织。

## 5. 逐图规划字段

| 字段 | 说明 |
|---|---|
| 图片序号 | 推荐展示顺序 |
| 图片目的 | 该图承担的信息任务 |
| 画面内容 | 主体、场景、细节或截图 |
| 图片文案 | 图上需要呈现的文字 |
| 素材来源 | 已有素材、待拍摄、待截图或待制作 |
| 制作备注 | 构图、裁切、重点标注和留白 |
| 正文对应 | 与哪部分正文关联 |

每张图片应有不同作用，避免同一信息反复出现。

## 6. 缺少图片时

给出具体拍摄或制作建议，包括拍什么、从什么角度、展示什么细节、是否需要截图或信息图。不能把建议描述成已完成的图片。若宿主具备图像生成能力且用户明确要求生成图片，可进一步调用；否则只交付视觉方案。

## 7. 图文一致性检查

封面是否准确代表主题？图片是否支撑正文信息？图片文案是否与正文重复过多？顺序是否帮助读者理解？是否有模糊、重复或不必要的图片？是否存在未经确认的信息或未经授权的素材？
