# 工作流程与创作决策

## 1. 最小创作简报

在内部形成以下信息，不必每次展示给用户：

| 项目 | 需要判断什么 |
|---|---|
| 任务 | 创作、改写、策划、图文规划、参考分析或复盘 |
| 读者 | 谁会看，处于什么场景或认知阶段 |
| 目标 | 分享、解决问题、提供知识、帮助决策、介绍产品等 |
| 读者价值 | 看完能获得什么 |
| 内容承诺 | 标题和开头承诺了什么 |
| 素材依据 | 有哪些事实、体验、观点和待确认信息 |
| 形式 | 叙事、教程、清单、对比、测评、观点等 |
| 交付 | 成稿、备选、图文规划、表格或其他成果 |

## 2. 任务路由

| 输入 | 推荐路径 |
|---|---|
| 一句话主题 | 简报 → 角度选择 → 成稿 |
| 主题 + 目标受众 | 读者价值 → 内容结构 → 成稿 |
| 图片/截图 | 可见信息提取 → 图片关系判断 → 内容组织 → 图文规划 |
| 产品资料 | 参数/功能提取 → 事实依据判断 → 产品介绍或选购内容 |
| 用户体验 | 经历提取 → 细节与感受组织 → 体验笔记 |
| 已有草稿 | 诊断 → 针对性修改 → 回查原意 |
| 参考笔记 | 结构拆解 → 方法提炼 → 原创迁移 |
| 多个选题 | 角度生成 → 价值比较 → 选题交付 |
| 数据 | 指标口径确认 → 比较 → 假设 → 下一轮验证 |

## 3. 何时追问

仅在信息缺失会明显改变内容方向或造成事实失真时追问。典型情况：
- 用户要求真实测评，但没有说明是否使用过产品。
- 探店笔记没有店铺、地点或任何体验资料。
- 产品关键参数存在冲突。
- 目标读者决定内容难度，但用户没有提供且无法合理推断。
- 图片或附件不可读取，而任务必须依赖其中的信息。

一次只问最关键的问题。能先完成的部分先完成；用户要求先出初稿时，可用中性表达并标记待补充项。

## 4. 选题角度决策

复杂策划时先产生少量有差异的候选方向，再根据以下维度比较：
- 目标是否匹配。
- 读者是否有明确收获。
- 现有素材是否能支撑。
- 是否有具体切入点和差异性。
- 内容形式是否适配。
- 是否需要未经确认的事实。

简单单篇创作时在内部完成判断，不必把全部候选都展示给用户。

## 5. 工作量控制

- 只改标题：只改标题。
- 简单创作：直接成稿。
- 素材较多：先提炼，再组织内容。
- 完整图文：同时处理正文和逐图规划。
- 批量选题：适合使用表格。
- 参考研究或数据复盘：提供依据、局限和行动建议。

## 6. 多轮协作

保留本轮已确认的事实、目标和风格。用户否定某种表达后，后续版本应改变对应写法。只修改用户要求的部分，除非其他部分存在事实或逻辑硬伤。修改后检查是否改变事实、破坏原有重点或引入新问题。
