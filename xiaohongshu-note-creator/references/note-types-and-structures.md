# 笔记类型与结构参考

这些结构是可选方法，不是固定模板。根据读者价值、素材和表达目标灵活组合。

## 1. 生活记录
具体场景 → 过程细节 → 个人感受 → 自然收尾。突出生活细节和个人视角，不强行升华成大道理。

## 2. 经验分享
遇到的问题 → 当时的条件 → 采取的方法 → 结果或反思 → 适用边界。避免把个人经验说成普遍适用的方法。反思只整理用户已经说出的做法，不补“我以前习惯”、年限或“住几年再买”。

## 3. 教程攻略
适用对象与目标 → 前提准备 → 操作步骤 → 易错点 → 结果检查。步骤只整理用户已经做过的动作，或用户明确要求的通用做法。没有做过的清空、分堆、断舍离和到点停止，不要写成用户的方法。不把原话里的放置写成踮脚、找领口或搬走箱子。

## 4. 产品介绍
具体需求场景 → 产品是什么 → 已确认功能与特点 → 适用人群/场景 → 需要进一步确认的条件。不能把产品参数改写成未经证实的效果。“适合放在桌上”只说明摆放，不说明效果覆盖范围。容量不能写成续航或加水次数，例如不能由 300ml 写成“工作日要加水”。USB 供电不能解释成电脑口、充电头或免适配器。未知项只用问句，问句里不给估计答案。没有价格就不评价贵贱。可复制正文不写“我看这种”。

## 5. 真实测评
体验背景 → 真实过程 → 优点 → 不足 → 适用人群 → 有边界的结论。必须有真实体验素材。

## 6. 探店与本地体验
地点/主题 → 实际体验 → 环境/服务/菜品等细节 → 个人评价 → 实用信息。地点、价格、营业时间和消费过程不得猜测。

## 7. 美食与食谱
成品或场景 → 食材/工具 → 步骤 → 关键细节 → 失败点或替代方案。未提供的配比、时长和效果不应伪造。

## 8. 旅行与出行
目的地/行程背景 → 路线或体验 → 重要细节 → 费用/时间等实用信息 → 适用建议。实时信息需核验；个人体验不能虚构。

## 9. 知识科普
问题 → 核心概念 → 解释 → 例子 → 适用边界。重要事实应有可靠依据，避免过度简化导致错误。

## 10. 清单合集
清单适用对象 → 筛选标准 → 条目与差异 → 使用/选择建议。条目应有依据，不能为凑数量编造。

## 11. 观点表达
明确观点 → 形成背景 → 理由/例子 → 不同情况 → 总结。区分事实、判断和个人偏好。

## 12. 故事叙述
只重排用户已经写出的场景、动作和感受。时间词不能加细：只写了“周末”，就不能写“周六”或“下午”。衣物只用原词：写了“厚衣服”，就不能写成毛衣或羽绒服。不补姿势、家具和前后观感，例如坐在地板上、柜杆、踮脚、关门后更安静。不能替用户编造对话、情节和心理活动。

## 13. 对比与消费决策
决策问题 → 比较对象 → 统一维度 → 差异解释 → 不同需求下的选择。比较口径应一致，缺少数据时不虚构评分和排名。

## 14. 商业合作内容
需求场景 → 产品/服务价值 → 有依据的特点 → 适用人群 → 合作信息披露与行动方式。表达应自然，但不得伪造使用体验、评价或效果承诺。

## 15. 选题与系列内容
系列策划时明确每篇的主题、读者价值、素材需求和与其他篇目的差异。避免同一主题换标题重复发布。
