# 小红书笔记创作（Xiaohongshu Note Creator）

**版本：** 1.1.2  
**分类：** 内容创作  
**许可证：** MIT

## 能做什么

从一句想法、一组素材、一份产品资料、一段真实经历或现有草稿出发，写成可以直接使用的小红书笔记。也可以做选题、改写、多版本、图文规划和基于用户数据的复盘。

1.1.2 继续收紧可复制正文：容量不写成续航或加水次数，USB 供电不解释成具体接口；故事里的时间、衣物和动作必须对上原词。事实够用时直接交付成稿。

## 安装

下载 `xiaohongshu-note-creator.zip`，在支持导入 Skill 的 Agnes 客户端或管理界面上传。不同客户端的导入入口可能不同。

## 调用示例

- “我想写一篇小红书，分享第一次自己做手冲咖啡的过程，语气自然一点。”
- “我上传了几张周末露营照片，帮我挑选封面，整理成图文笔记并规划每张图。”
- “根据这份产品资料写一篇介绍，不要假装自己用过。”
- “这篇笔记太像 AI 了，先判断具体问题，再改得自然一点。”
- “围绕同一个主题给我三个不同角度，正文也要有实质差异。”

## 能力依赖

基础策划和写作不依赖外部 API/MCP。图片理解、文件读取、联网搜索、图像生成和 XLSX 生成取决于宿主环境是否提供相应工具。工具不可用时，会说明限制并提供可行替代。
