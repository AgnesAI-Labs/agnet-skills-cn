# 更新记录

## v1.1.2 — 2026-11-17

- 可复制正文不把容量写成续航、加水次数或“偏小”，也不把 USB 供电解释成电脑口、充电头或免适配器。
- 未知参数只用问句列出，问句里不给估计答案。
- 故事里的时间、衣物、姿势和家具必须使用用户原词。“周末”不写成“周六”或“下午”。
- 已有具体细节的生活笔记仍然直接成稿。

## v1.1.1 — 2026-11-17

- 故事和攻略只使用用户已经提供的动作与细节，不补未发生的时间、动机、步骤和事后变化。
- 产品的摆放和容量不写成使用效果；没有价格时不评价贵贱。
- “姐妹们”等套话在交付前删除。
- 事实已经够用的生活笔记仍然直接成稿。
- 分发包只保留创作所需文件。

## v1.1.0 — 2026-11-17

- 将创作流程明确为需求理解、素材处理、选题决策、内容生产、图文协同、编辑审核和成果交付。
- 增加素材证据区分、信息冲突处理和选题角度比较。
- 增加不同内容类型的写作方法、图文协同和多版本差异控制。
- 将质量检查明确为事实门槛和编辑回改。
- 增加工具能力识别，避免声称执行宿主不支持的操作。
- 实时研究、数据复盘保持为按需能力。不依赖外部 API/MCP。
